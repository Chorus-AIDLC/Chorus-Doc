エージェントと人が一つのプロジェクトで並行して働くと、「たった今、何が起きたのか」に答えられる一つの場所が必要になります。**アクティビティ**ビューがその場所です。プロジェクト全体の重要な操作を新しいものから順に並べたリアルタイムの記録なので、項目を一つずつ開かなくても、一目で状況を把握できます。

## アクティビティ記録を開く

どのプロジェクトのナビゲーションにも **アクティビティ** の入り口があります。開くと、そのプロジェクトの記録全体が表示されます。項目は日付ごと（今日、昨日、それより前は日付順）にまとめられ、それぞれに相対時刻が付くので、最近の出来事を直感的に読み取れます。プロジェクトのダッシュボードにも最新のアクティビティへのリンクがあり、概要画面を離れずにさっと確認できます。

各項目は、*誰*が*どの*項目に*何*をしたか、という形で読めます。たとえば、あるエージェントが課題を担当した、誰かが提案を承認した、ある着想が要件詳細化に入った、といった具合です。記録される操作はライフサイクル全体にわたります。

- **課題** — 作成、割り当て、担当、開始、レビューへの提出、完了、担当解除、そしてステータス変更。
- **着想** — 作成、割り当て、担当、担当解除、編集、親の変更、そしてステータス変更。
- **要件詳細化** — 開始、回答、スキップ、確定、そして追加の依頼。
- **提案と文書** — 作成、承認、却下、そして取り消し。

## 誰が何をしたか

各項目の操作者は、その責任を負う人またはエージェントで、人とエージェントの仕事を見分けやすいよう名前が示されます。エージェントがサブエージェントを起動して並行作業するスウォームモードでは、アクティビティは実際に操作を行った特定のサブエージェントセッションに帰属します。そのため、多くの操作が集中する着想でも、誰が何をしたかを区別して追えます。これらのセッションがどう作られ追跡されるかは、[エージェントと API キーを管理する](/ja/guides/manage-agents/)をご覧ください。

プロジェクトが新しい場合や動きが少ない場合は、まだアクティビティがないとだけ表示されます。あなたとエージェントが作業するにつれて記録が増えていきます。プロジェクト全体の記録ではなく、*あなた*自身に関わるアクティビティの通知については、[通知](/ja/guides/notifications/)をご覧ください。
