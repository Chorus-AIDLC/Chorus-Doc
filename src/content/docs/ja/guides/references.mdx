Chorus での仕事は、単独で成り立つことはめったにありません。参照している公式ドキュメント、手本にしているリポジトリ、問題が報告された issue のスレッド、アプローチのヒントになった記事など、何らかの拠り所があるものです。**参考資料** は、その根拠を URL、タイトル、重要な理由を書く任意のメモからなるリンクとして記録します。Chorus はそのリンクとあなたのメモだけを保存します。URL の先のページを取得・ダウンロード・スナップショットすることは決してありません。

参考資料は **着想**、**提案**、または **課題** に添付でき、根拠がそれを支える仕事のすぐそばに置かれます。エージェントが課題を担当すると、添付した参考資料も一緒に引き継がれます。また、エージェントが計画を提案するときは、参照した出典を添付できるので、あなたが確認できます。

## 参考資料を追加する

着想・提案・課題を開き、その **参考資料** の節（提案パネルではカード、課題と着想では見出し付きの節）を見つけます。**参考資料を追加** を選び、次を記入します。

- **種類** — 四種のうちの一つで、それぞれ独自のアイコンとバッジで示されます。
  - **ドキュメント** — 公式のドキュメント。
  - **リポジトリ** — 参考実装またはコードベース。
  - **Issue / PR** — issue または pull request のスレッド。
  - **論文 / ブログ** — 論文またはブログ記事。
- **URL** — ウェブのリンク（`http://` または `https://`。ローカルファイルは受け付けません）。
- **タイトル** — 参考資料の短い名前。
- **メモ** — 任意。なぜその参考資料が関連するかを、簡潔な一文で。表示されるのは最初の二行だけなので、短くまとめてください。全文はホバーで確認できます。

参考資料はすぐに節に表示されます。どの参考資料も同じ場所から編集・削除できます。削除するとリンクは Chorus から取り除かれ、元に戻せません。

## インライン引用を読む

説明・文書・コメントでは、主張をしているその場所で参考資料を引用できます。引用は本文中に **[1]** のような括弧付きの小さな番号として表示されます。

- **ホバーまたはフォーカスする** と、参考資料の現在のタイトル、種類、URL、メモが見られます。本文が書かれた後に参考資料が編集されていれば、最新の版が表示されます。
- **選択する** と、出典が新しいタブで開きます。
- **灰色** の引用は開けません。ホバーまたはフォーカスすると理由がわかります。参考資料がもう存在しない（**エビデンスが見つかりません**）、詳細をまだ読み込み中、あるいは読み込みに失敗した、のいずれかです。失敗した場合は、次にホバーまたはフォーカスしたときに再試行します。

引用は、いま読んでいる項目に添付されたものに限らず、あなたがアクセスできる任意の参考資料を指せます。[着想](/ja/guides/capture-an-idea/#開発の前にリサーチを依頼する)のリサーチでは、この仕組みで調査結果の一つひとつを出典に結びつけています。

## エージェントは参考資料をどう使うか

エージェントもあなたと同じ方法で参考資料を添付します。そのため、提案は最初から出典の裏付けが付いた状態で届くことがあります。`document:write` 権限を持つエージェントは、`chorus_add_reference`、`chorus_update_reference`、`chorus_remove_reference` の三つのツールを使えるほか、着想・提案・一組の課題を作るときにインラインで参考資料を添えることもできます。着想・提案・課題を読む人は誰でも、その参考資料をインラインで見られます。特別な権限は要りません。

エージェントは引用を、参考資料の ID への通常の Markdown リンクとして書きます。たとえば `[1](ref:<reference-uuid>)` のように、参考資料を添付または読み取ったときに Chorus が返す ID を使います。どの参考資料にも一致しない ID は **エビデンスが見つかりません** と表示されるので、エージェントは先に参考資料を添付するか調べる必要があり、ID を捏造してはいけません。

エージェントには出典を示す習慣を付けさせる価値があります。対象とする API ドキュメントそのものをリンクした提案は、ただ信用するよう求める提案よりもはるかに検証しやすくなります。これらのツールを利用するための権限が、権限モデル全体の中でどう位置づくかは[認証と権限](/ja/reference/authentication/)を、ツール自体は [MCP ツールカタログ](/ja/reference/mcp-tools/)をご覧ください。
