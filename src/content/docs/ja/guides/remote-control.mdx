エージェントランタイムがすでに**オンライン**（Online）で、Chorus からそのマシンで作業を始めたいときは、リモートで作業を開始します。

## ランタイムを選ぶ

作業を始める前に、次を確認します。

- エージェントのアイデンティティが、そのプロジェクト向けに意図したものであること。
- 接続が**オンライン**（Online）であること。
- ホストが、期待するマシンであること。
- 作業ディレクトリに、変更したいプロジェクトが含まれていること。

プロジェクトや課題が特定の接続に固定されている場合、Chorus はそのホストと作業ディレクトリを使い続けます。その接続がオフラインなら、復旧させるか、明示的に別のターゲットを選びます。Chorus が固定された作業を黙って別の場所へ移すことはありません。

:::caution[作業ディレクトリが実行コンテキストを定義する]
エージェントは、選ばれたディレクトリへのアクセス権と、そのデーモンに設定された権限モードで実行されます。指示を送る前にターゲットを確認してください。
:::

## セッションを開始する

1. エージェントに扱わせたいプロジェクトの項目を開きます。
2. エージェントの作業を開始または継続するアクションを選びます。
3. オンラインの作業ディレクトリを選びます。
4. 期待する結果と制約を含めて、具体的な指示を入力します。
5. **セッションを開始**（Start session）を選びます。

## モバイルで会話を確認する

小さい画面では、会話がほぼ全画面のパネルで開きます。戻るボタンでセッション一覧に戻り、別の会話を選べます。
アクティブなセッションを選ぶと、一覧のまだ読み込まれていない部分にあっても直接開きます。
エージェントのセッション ID が利用可能になると、コンパクトなトランスクリプトのヘッダーにある
**セッション ID をコピー**を使って、ターミナルでセッションを続けられます。

## 結果を観察する

会話を開いて、現在のターンとエージェントの出力を追います。目を離す前に、選んだ接続でセッションが始まっていることを確認します。

セッションが始まらない場合は、まずターゲットがまだオンラインかを確認します。配信の失敗には[エージェント接続のトラブルシューティング](/ja/guides/troubleshooting/)を使ってください。セッションはすでに始まっていて介入が必要なときは、[セッションを中断して再開する](/ja/guides/session-recovery/)を使ってください。
