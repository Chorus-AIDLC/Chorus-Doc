このページは、アカウントにまつわるすべてを扱います。サインイン、複数のワークスペースの切り替え、初回オンボーディングウィザード、言語とテーマのコントロール、そしてサインアウトです。自分のマシンに初めて
Chorus をインストールするなら、まず[はじめに](/ja/guides/getting-started/)をご覧ください。そちらでローカルのメール／パスワードによるインストールを扱っており、このページでは繰り返しません。

## サインイン

Chorus はメールアドレスでサインインします。メールアドレスを入力して **続ける**を選ぶと、次にどこへ進むかはアカウントの設定によって変わります。

- **シングルサインオン（SSO）。** メールアドレスがアイデンティティプロバイダーを使う一つのワークスペースに属している場合、Chorus はそのプロバイダーの画面に移動し、認証が済むと Chorus に戻ります。（デプロイを運用していて SSO を有効にする必要がある場合は、[スーパー管理者と SSO のセットアップ](/ja/guides/authentication-setup/)をご覧ください。）
- **複数のアイデンティティから選ぶ。** そのメールアドレスで複数の方法でサインインできる場合、Chorus はどれか一つを選ぶよう求めます。たとえばパスワード、SSO、スーパー管理者などです。
- **ワークスペースを選ぶ。** メールアドレスが複数の SSO ワークスペースに属している場合、Chorus は下記のワークスペース選択画面に案内します。

インストールが組み込みのメール／パスワードによるサインイン（[はじめに](/ja/guides/getting-started/)のローカル単一ユーザー構成）を使う場合は、メールアドレスとパスワードを入力します。ワークスペースが
SSO にも対応している場合は、同じ画面から切り替えられます。

## ワークスペースを選ぶ

一つのメールアドレスが複数のワークスペースに属することがあります。その場合、Chorus は各ワークスペースを名前とアイデンティティプロバイダーで一覧表示する選択画面を表示します。一つを選ぶと、Chorus
はそのワークスペースのサインインへ案内します。ここから別のメールアドレスに切り替えることもできます。

## 初回オンボーディング

まっさらなワークスペースに初めて入ると、Chorus は 6 ステップのオンボーディングウィザードを開きます。スキップして後で完了することもできます。ウィザードは次を案内します。

1. **ようこそ**：作業が通るパイプラインの全体像を示します。
   **着想 → 提案 → 課題 → 実行 → 検証 → 完了**。
2. **エージェントを作成**：AI エージェントに名前を付けて権限を選ぶと、Chorus がその API キーを生成します。（エージェント設定の全体は[エージェントのアクセスを準備する](/ja/guides/administrator-setup/)にあります。ここはその手早いインライン版です。）
3. **キーをコピー**：安全な場所に保存してください。表示されるのは一度きりです。
4. **インストール**：エージェントクライアント（Claude Code、Codex、Kiro、OpenCode、OpenClaw
   など）を選び、表示されるセットアップ手順に従います。
5. **テスト**：Chorus はエージェントが接続するまで待ち、接続を確認します。
6. **完了**：セットアップの概要と、プロジェクトや設定へのショートカットが表示されます。

ウィザードはいつでも **設定**から再度開けます。

:::note[エージェントは何をするのか]
**エージェントを作成** と **テスト** のステップは、AI エージェントの ID を設定し、検証します。エージェントを作成してそのクライアントをインストールすると、エージェントは自分で
Chorus に接続します。**テスト** ステップはその接続を見守るだけです。各クライアントプラットフォームがどのように接続し振る舞うかは、[エージェントプラットフォーム](/ja/reference/agents/)をご覧ください。
:::

## 言語とテーマ

表示に関する設定はサイドバーのフッターにあります。

- **テーマ**：**ライト**、**ダーク**、**システム**（OS の設定に従う）から選べます。
- **言語**：**English**、**中文**、**한국어**、**日本語** から選ぶと、インターフェースがすぐに切り替わります。**設定**ページからも言語を変更できます。

## サインアウト

サイドバーのフッターには **サインアウト**ボタンがあります。選ぶとセッションが終了し、サインイン画面に戻ります。そこから同じメールアドレスでも別のメールアドレスでも再度サインインできます。

## 次へ

アカウントとエージェントが整ったら、[AI-DLC ワークフロー](/ja/guides/ai-dlc-workflow/)を読んで、仕事が着想から完了までどう進むかを確認してください。あるいは直接[着想を記録](/ja/guides/capture-an-idea/)に進んでもかまいません。
