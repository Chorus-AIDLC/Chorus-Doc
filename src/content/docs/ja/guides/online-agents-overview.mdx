Chorus は、あなたがオンラインに保っているマシン上でエージェントの作業を開始し、制御できます。このページでは、その仕組み（オンラインエージェントとは何か、プロジェクトが作業をどのように一つのエージェントに固定するか、一つの会話がどのように着想に対応するか、中断・再開・引き継ぎをどう行うか）を説明し、実際に各操作を行うページを案内します。これらのエージェントが実行する協働のワークフローについては[AI-DLC ワークフロー](/ja/guides/ai-dlc-workflow/)を、公開されるプラグインのコマンドについては[コマンドとスキルルーティング](/ja/guides/plugin-commands/)をご覧ください。

## オンラインエージェントとは

**オンラインエージェント**とは、エージェントの API キーで認証され、Chorus との接続を維持している `chorus daemon` プロセスです。このプロセスが動いている間、Chorus はそれを通じて、作業を開始したり、追加の指示を送ったり、実行中のターンを中断したり、止まったターンを再開したりできます。あなたがマシンを直接操作する必要はありません。

各接続は三つのもので指定されます。**エージェント**のアイデンティティ（API キー）、それが動く**ホスト**、そしてそれが提供する**作業ディレクトリ**（`cwd`）です。一つのデーモンは複数の独立したエージェント（それぞれ自分のキーとアイデンティティを持つ）をホストでき、エージェントごとに複数のディレクトリを提供できます。登録された `(agent, host, directory)` の組み合わせは、それぞれ個別に指定できるターゲットになります。Chorus は各接続の接続状態（オンラインかオフラインか）を、バックエンド、ホスト、ディレクトリとともに**設定 → エージェント**（Settings → Agents）に表示します。

## プロジェクトのディレクトリを固定する仕組み

プロジェクトは、特定のオンラインエージェントと作業ディレクトリに**固定**できます。固定すると、そのプロジェクトの UI から始めたエージェントの作業は同じ接続と同じディレクトリに送られ、作業ディレクトリのピッカーは表示されなくなります。毎回ターゲットを選び直す必要はありません。この設定の指定・変更・解除の方法は[プロジェクトを作成](/ja/guides/create-a-project/)をご覧ください。

## 着想ごとに一つのセッション

着想ごとに会話は一つだけです。そのため、その着想でエージェントの作業を始めるたびに、同じ会話に届きます。別の作業ディレクトリからその着想の作業を始めると、Chorus は二つ目の会話を始めるのではなく、その一つのセッションを新しいディレクトリへ**移す**ので、着想の履歴は一続きのまま保たれます。

## 中断、再開、引き継ぎ

エージェントが作業している間、あなたは現在のターンを**中断**したり、文脈を追加して止まった会話を**再開**したり、コピーしたセッション ID を使ってターミナルから会話を**引き継いだり**できます。これらの操作は、新しい会話を始めるのではなく、既存の会話に作用します。[セッションを中断して再開する](/ja/guides/session-recovery/)をご覧ください。

OpenClaw は `chorus daemon` ではなく OpenClaw ゲートウェイを通じて接続する、ゲートウェイ型の接続です。[OpenClaw](/ja/reference/agents/openclaw/)をご覧ください。

## 各操作をどこで行うか

オンラインエージェントの各機能には、それを操作する場所と、詳しく説明しているページがそれぞれ一つずつあります。

| 機能 | 操作する場所 | 詳細 |
| --- | --- | --- |
| 中断と再開 | 会話の**中断**（Interrupt）と**再開**（Resume）のコントロール | [セッションを中断して再開する](/ja/guides/session-recovery/) |
| 作業の開始（ビジー時はキューに入る） | プロジェクトの項目からエージェントの作業を開始または継続する。ビジーなディレクトリへのリクエストは、空くまでキューに入る | [リモートのエージェントで作業を始める](/ja/guides/remote-control/) |
| `(agent, host, cwd)` の指定 | デーモンを起動するときに各作業ディレクトリを登録する（繰り返し可の `--cwd`） | [Chorus デーモンを運用する](/ja/guides/daemon-operations/) |
| 接続状態 | **設定 → エージェント**（Settings → Agents）が各接続のオンライン状態、バックエンド、ホスト、ディレクトリを表示する | [エージェントランタイムを接続する](/ja/guides/operator-onboarding/) |
| リモート起動 | オンラインのディレクトリを選び、指示を入力し、**セッションを開始**（Start session）する | [リモートのエージェントで作業を始める](/ja/guides/remote-control/) |
| 臨時の「オンラインのディレクトリで続ける」 | 新規着想ダイアログの対話モードで、新しい着想をオンラインのエージェントに渡す | [着想を記録](/ja/guides/capture-an-idea/) |
| 複数バックエンド（Claude Code、Codex、Kiro、Pi、DeepSeek Harness） | `--agent` で接続ごとにバックエンドを選ぶ | [エージェントプラットフォーム](/ja/reference/agents/) |
