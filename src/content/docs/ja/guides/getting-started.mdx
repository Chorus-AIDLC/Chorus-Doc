このガイドでは、新しいマシンにローカルの Chorus をインストールし、動かすまでを案内します。[Node.js 22 以降](https://nodejs.org/)と npm が必要です。

## Chorus をインストールして起動する

Chorus コマンドをグローバルにインストールします。

```sh
npm install --global \
  @chorus-aidlc/chorus
```

管理者アカウントを設定して Chorus を起動します。

```sh
DEFAULT_USER=you@example.com \
DEFAULT_PASSWORD='choose-a-strong-password' \
chorus
```

Chorus はローカルデータベースを作成し、必要なマイグレーションを適用して、Web アプリケーションを起動します。Chorus を使っている間は、このターミナルを開いたままにしてください。

## サインインする

`http://localhost:8637` を開き、上で設定したメールアドレスとパスワードでサインインします。共有マシンではこれらの値をシェル履歴に残さないでください。組み込みデータベースはローカルの単一ユーザー用途を想定しています。共有インストールでは、外部の PostgreSQL データベースまたは対応済みの Docker デプロイを使い、認証情報はデプロイ環境で管理してください。

## エージェントを接続する

1. **設定**（Settings）を開きます。
2. **セットアップガイド** を見つけ、**セットアップガイドを開く** を選びます。
3. エージェントプラットフォームを選びます。
4. 表示されたインストールと接続の手順に従います。
5. ガイドの接続チェックを完了します。

セットアップガイドは必要なエージェントの認証情報を作成し、選んだプラットフォーム向けのコマンドを提供します。別のプラットフォームのコマンドを流用しないでください。

ターミナル派なら、代わりに CLI をインストールしてコマンドを 1 つ実行するだけで済みます。

```sh
npm install --global @chorus-aidlc/chorus
chorus agents add
```

`chorus agents add` は、すでにインストールしているエージェントを検出し、それぞれの Chorus プラグインをインストールして、認証情報を設定します。[chorus CLI](/ja/reference/cli/) と[エージェントランタイムを接続する](/ja/guides/operator-onboarding/)を参照してください。

プラットフォームの比較方法、Chorus プラグインに何が同梱されているか、アップグレードやアンインストールの方法など、エージェント設定の全体像は[エージェントプラットフォーム](/ja/reference/agents/)をご覧ください。アクセスキー、リモート起動、ランタイムをオンラインに保つ方法については、[エージェントのアクセスを準備する](/ja/guides/administrator-setup/)から始まる一連のガイドをご覧ください。

次にやりたいことを選びます。

- **エージェントのターミナルから Chorus を使う:** プラットフォームページのチェックイン手順を完了します。OpenCode、Pi、汎用 MCP クライアントはここで完了です。これらはリモートから利用できるランタイムとしては表示されません。
- **Chorus からリモートで作業を始める:** Claude Code、Codex、Kiro、または OpenClaw を使います。Claude Code、Codex、Kiro については、[ランタイムを接続](/ja/guides/operator-onboarding/)し、[オンラインに保ち](/ja/guides/daemon-operations/)、それから[最初のセッションを開始](/ja/guides/remote-control/)します。OpenClaw は自前のゲートウェイを通じてオンラインを維持します。

マシンや認証情報を別の担当者が管理している場合は、[エージェントのアクセスを準備する](/ja/guides/administrator-setup/)から始めてください。

## 最初の着想を動かす

Chorus が動き、エージェントが接続できたら、実際に使ってみましょう。一連の流れを最も手早く体験するには、小さな着想を一つ、最初から最後まで進めてみることです。

1. 作業を収める[プロジェクトを作成](/ja/guides/create-a-project/)します。
2. [着想を記録](/ja/guides/capture-an-idea/)します。*「このリポジトリに README を追加する」* のような、小さくても実際の作業で構いません。そしてエージェントの要件詳細化の質問に答えます。
3. エージェントが起草した[提案を審査](/ja/guides/review-a-proposal/)し、承認します。
4. エージェントに[課題を実行](/ja/guides/run-tasks/)させ、結果を[検証して完了](/ja/guides/verify-and-complete/)します。

リクエストが着想から完了までどう進み、どこであなたが判断するのか、その全体像は [AI-DLC ワークフロー](/ja/guides/ai-dlc-workflow/)をお読みください。そこから各段階の手順ガイドへ進めます。
