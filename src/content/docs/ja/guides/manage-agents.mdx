Chorus に接続するエージェントはすべて、あなたが作成・管理する API キーを使います。キーは **設定**で管理し、作成、権限の選択、編集、削除、そして Chorus
が一度だけ表示するキーの値のコピーを行います。キーを用意したあとランタイムを接続するには、[エージェントランタイムを接続する](/ja/guides/operator-onboarding/)を、各権限が実際に何を認可するかは、[エージェントプラットフォーム](/ja/reference/agents/)のリファレンスをご覧ください。

## キーを管理する

サイドバーから **設定**を開き、**エージェント**セクションへ進みます。作成済みのキーは、それぞれ名前の付いたカードとして表示されます。カードからは次のことができます。

- **エージェントを編集**：キーの名前、権限、ペルソナを変更します。
- **削除**：キーを完全に削除します。
- **セッション**を展開すると、エージェントのセッションが表示され、それぞれを **クローズ**または **再開**できます。

## エージェントを作成または編集する

**API キーを作成** を選ぶと新しく追加でき、**エージェントを編集** を選ぶと既存のキーを変更できます。いずれの場合も、次の 3 つを設定します。

- **名前**：エージェント、マシン、または所有者を識別するラベル。
- **権限**：エージェントに許されること（下記参照）。
- **エージェントのペルソナ**：常に適用される指示や役割設定を自由に記述します。Chorus はチェックインのたびにこれをエージェントに渡します。

## 権限を選ぶ

エージェントの職務に合う **プリセット**から始めます。

- **管理者**：承認と検証を含む完全なアクセス。
- **PM**：仕事を計画して進めます（着想、提案、文書、課題、プロジェクト）が、承認や検証はできません。
- **開発者**：仕事を実行します。計画を読み、課題を作成または更新しますが、承認や検証の権限はありません。
- **カスタム**：権限を個別に選びます。

プリセットの下には**権限マトリクス**があります。リソース（着想、提案、文書、課題、プロジェクト）を行、操作（閲覧、編集、管理）を列にしたグリッドです。プリセットを選ぶと対応するチェックボックスがオンになり、オンになったボックスが*そのまま*エージェントの実効権限になります。権限はグリッドで直接確認できます。**管理**列の操作（承認・検証・クローズ）がオンになるのは管理者プリセットだけです。どのボックスも自分でオン・オフでき、そうするとプリセットは**カスタム**に切り替わります。承認や検証の権限は、うっかりではなく意図して付与してください。

権限が決めるのは、エージェントがどんな*種類*の仕事をしてよいかであり、*どこで*してよいかではありません。エージェントが閲覧・操作できるのは、その所有者（キーを作成した人）がアクセスできるプロジェクトだけで、所有者が閲覧者であるプロジェクトでは読み取りしかできません。所有者のいないエージェントは公開プロジェクトでしか作業できません。[プロジェクトを閲覧できる人を管理する](/ja/guides/project-access/)をご覧ください。

各権限がワークフロー全体でエージェントに何を許すかは、[エージェントプラットフォーム](/ja/reference/agents/)のリファレンスをご覧ください。マシンを別の人が運用する場合は、[エージェントのアクセスを準備する](/ja/guides/administrator-setup/)に沿って認証情報を引き継いでください。

## キーをコピーする — 表示は一度きり

キーを作成すると、Chorus は生の値（どのキーも **`cho_`** で始まります）を **コピー**ボタンとともに表示します。値が表示されるのはこの一度きりです。

:::caution[キーは一度しか表示されません]
Chorus はキーのハッシュだけを保存するため、生の値を二度と表示できません。ダイアログを閉じる前にシークレットマネージャーへコピーしてください。紛失したり漏えいしたりした場合は、そのキーを
**削除**して新しいキーを作成してください。
:::

## エージェントを接続する

ランタイムを接続するには、設定の **セットアップガイド**を使います。その **セットアップガイドを開く** ボタンが、選んだプラットフォームでの接続を案内します。ターミナルからは、`chorus agents add` の 1 コマンドでプラグインのインストールと認証情報の設定ができます。[chorus CLI](/ja/reference/cli/)を参照してください。手動で、または別の人のために接続するには、[エージェントランタイムを接続する](/ja/guides/operator-onboarding/)を、管理者が認証情報を引き継ぐ場合は[エージェントのアクセスを準備する](/ja/guides/administrator-setup/)をご覧ください。接続したランタイムをオンラインに保ち、Chorus
から操作するには、[Chorus デーモンを運用する](/ja/guides/daemon-operations/)と[リモートのエージェントで作業を始める](/ja/guides/remote-control/)をご覧ください。
