本ドキュメントで使われる用語の早見表です。各項目では、製品内での名称、一行の定義、そして詳しい説明が
ある場所へのリンクを示します。各エンティティが経ていく状態は[エンティティのライフサイクルリファレンス](/ja/reference/lifecycle/)を、
各段階がどう引き継ぐかは[ワークフローリファレンス](/ja/reference/workflow/)をご覧ください。

## 中核エンティティ

<div class="table-scroll" role="region" aria-label="中核エンティティの用語" tabindex="0">

  | 用語 | 定義 |
  | --- | --- |
  | **Idea**（着想） | パイプラインに入るリクエスト。提案が起草される前に要件詳細化を経る。[着想を記録](/ja/guides/capture-an-idea/)を参照。 |
  | **Proposal**（提案） | 文書ドラフトと課題ドラフトをまとめてレビューするための入れ物。承認すると、実際の文書と課題として作成される。[提案を審査](/ja/guides/review-a-proposal/)を参照。 |
  | **Task**（課題） | 優先度、見積もり、受け入れ基準、依存を持つ作業単位。完了の前に検証される。[課題を実行](/ja/guides/run-tasks/)と[検証して完了](/ja/guides/verify-and-complete/)を参照。 |
  | **Document**（文書） | PRD、仕様、設計、レポートなどの書かれた成果物。提案の文書ドラフトから作成され、プロジェクトにひもづく。[提案を審査](/ja/guides/review-a-proposal/)を参照。 |
  | **Reference**（参考資料） | 着想・提案・課題にひもづく外部の裏づけへのリンク（ドキュメント、リポジトリ、issue/PR、論文/ブログ）。URL とメモが保存され、ページそのものは保存されない。[参考資料を添付する](/ja/guides/references/)を参照。 |
  | **Project**（プロジェクト） | あるプロジェクトの着想・提案・文書・課題をまとめて収める単位。[プロジェクトを作成](/ja/guides/create-a-project/)を参照。 |
  | **Project group**（プロジェクトグループ） | 関連するプロジェクトを一つの見出しの下にまとめるフォルダー。[プロジェクトを作成](/ja/guides/create-a-project/)を参照。 |
  | **Private project / group**（非公開プロジェクト／グループ） | メンバー（プロジェクトの場合はそのグループのメンバーも）と、そのメンバーが所有するエージェントだけが閲覧できるプロジェクトまたはグループ。ワークスペースのそれ以外の人は見つけられない。[プロジェクトを閲覧できる人を管理する](/ja/guides/project-access/)を参照。 |
  | **Viewer / Editor / Admin**（閲覧者／編集者／管理者） | メンバーが持てるロール。閲覧者は読み取りのみ（非公開プロジェクトの場合。公開プロジェクトでは全員が少なくとも編集者）、編集者は読み書き（提案の承認と課題の検証を含む）、管理者はそのすべてに加えて公開範囲とメンバーを管理できる。[プロジェクトを閲覧できる人を管理する](/ja/guides/project-access/)を参照。 |

</div>

## 要件詳細化と着想の形

<div class="table-scroll" role="region" aria-label="要件詳細化と着想の形の用語" tabindex="0">

  | 用語 | 定義 |
  | --- | --- |
  | **Acceptance criterion**（受け入れ基準） | 課題が検証されるために満たすべき、検証可能な一つの条件。[検証して完了](/ja/guides/verify-and-complete/)を参照。 |
  | **Elaboration round**（要件詳細化のラウンド） | 着想の要件を明確にする、構造化された一巡の質問と回答。要件詳細化は確定するまでラウンドを繰り返す。[着想を記録](/ja/guides/capture-an-idea/)を参照。 |
  | **Theme**（テーマ着想） | 関連する子の着想を共有の方向の下にまとめるだけの着想。テーマ自体は提案になれない。[着想を記録](/ja/guides/capture-an-idea/)を参照。 |
  | **Derived (child) idea**（派生した子の着想） | 自身の要件詳細化・提案・課題を持ち、親の着想にひもづいた完全な着想。[着想を記録](/ja/guides/capture-an-idea/)を参照。 |

</div>

## エージェントとリモート作業

<div class="table-scroll" role="region" aria-label="エージェントとリモート作業の用語" tabindex="0">

  | 用語 | 定義 |
  | --- | --- |
  | **Session / Conversation**（セッション / 会話） | エージェントの一回の作業セッション。デーモンのチャット画面はこれらを会話として、一つのやり取りを一つのターンとして示す。[Chorus デーモンを運用する](/ja/guides/daemon-operations/)を参照。 |
  | **Daemon**（デーモン） | エージェントをオンラインに保ち、リモートの作業のために起動できるようにする、長寿命のローカルプロセス。[Chorus デーモンを運用する](/ja/guides/daemon-operations/)と[リモートのエージェントで作業を始める](/ja/guides/remote-control/)を参照。 |

</div>
