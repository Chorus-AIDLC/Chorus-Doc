Chorus は、ワークスペース内のあらゆる種類のエンティティを横断する単一のグローバル検索を提供します。
サイドバーの検索ボタン、モバイルのヘッダーアイコン、または `Cmd+K`（`Ctrl+K`）のキーボード
ショートカットから開けます。本ページは、検索が何を対象にし、結果がどう区切られるかを説明します。

## 何が検索できるか

検索は六つのエンティティ種別にわたります。各種別で一致の対象となるフィールドは次のとおりです。

| エンティティ種別 | 一致するフィールド |
| --- | --- |
| 課題 | タイトル、説明 |
| 着想 | タイトル、内容 |
| 提案 | タイトル、説明 |
| 文書 | タイトル、内容 |
| プロジェクト | 名前、説明 |
| プロジェクトグループ | 名前、説明 |

一致は大文字小文字を区別しない部分文字列一致です。検索対象のテキストにクエリを含む
エンティティがすべて見つかります。各結果には、一致したテキストを文脈とともに示す短いスニペット、その状態、
そして属するプロジェクトが付きます。すべての種別の結果はまとめられ、最近更新された順に並びます。
課題・着想・提案・文書・プロジェクトのいずれか一つの種別に絞り込んで、その種別の結果を
より多く表示することもできます。

## 結果の範囲がどう決まるか

検索は常にあなたのワークスペースの中で実行され、他のワークスペースの結果が返されることはありません。また、返されるのは
あなたがアクセスできるものだけです。
閲覧できない[非公開プロジェクトやグループ](/ja/guides/project-access/)とその中のものは、
ID を正確に指定して検索しても結果に含まれません。ワークスペースの中では、
結果をさらに次の三つの範囲のいずれかに絞り込めます。

| 範囲 | 検索する対象 |
| --- | --- |
| グローバル | ワークスペース内のすべてのエンティティ。 |
| グループ | 特定のプロジェクトグループ内のすべてのプロジェクト。 |
| プロジェクト | 単一のプロジェクト。 |

Chorus は、あなたが今いる場所から妥当な既定の範囲を選びます。プロジェクト一覧では既定はグローバル、
プロジェクトグループの中ではそのグループ、プロジェクトの中ではそのプロジェクトが既定になります。範囲は
検索ヘッダーのセレクターからいつでも切り替えられます。

結果を選ぶと、そのエンティティの詳細ページ（課題・着想・提案・文書の各ページ、プロジェクトのダッシュボード、
またはプロジェクトグループのプロジェクト一覧）へ移動するため、検索は素早いナビゲーション手段にもなります。

:::note[エージェントは何をするのか]
エージェントは、すでに使っている Chorus のツールを通じて、同じ六つのエンティティ種別を同じ範囲指定で
検索します。そのため、行動を起こす前に着想・課題・文書を見つけられます。エージェントがどう接続するかは、
[エージェントプラットフォーム](/ja/reference/agents/)のリファレンスをご覧ください。
:::
