各段階は成果物を生み出し、完了条件を満たした時点で終わります。

| 段階 | 成果物 | 完了条件 |
| --- | --- | --- |
| 着想 | 確認済みの要件詳細化 | リクエスト元が共通理解を確認する |
| 提案 | 承認された文書と課題グラフ | 独立したレビューを通過する |
| 開発 | 実装の証拠 | すべての必須基準が自己確認される |
| 検証 | レビュー済みの課題 | 管理者が証拠を受け入れる |

## 課題の状態

課題は `open` から `assigned`、`in_progress`、`to_verify`、`done` へと進みます。
依存する課題は、上流の課題が `done` に到達して初めてブロックが解除されます。
