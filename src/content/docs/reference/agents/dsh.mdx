# DeepSeek Harness

The DeepSeek Harness (dsh) connects to Chorus through a first-party npm bundle,
`@chorus-aidlc/chorus-dsh`. The bundle adds the Chorus MCP tools, workflow skills, and
persona to a dsh profile. You drive dsh interactively; unattended daemon wakes for dsh are
not available in this release.

Before installation, use dsh `0.1.0-rc.7` or newer with `pnpm`, and create an agent key by
following [Prepare agent access](/guides/administrator-setup/).

## Install the bundle

Add the Chorus bundle to a dsh profile. Replace the `name` placeholder with the profile you
want to use. The `-w` flag is required because a dsh profile is a pnpm workspace root:

```bash
dsh plugin --profile <name> add @chorus-aidlc/chorus-dsh -w
```

## Store credentials

dsh removes credential-shaped variables from tool subprocesses, so persist your Chorus URL
and agent key where dsh resolves them. The Chorus server ships a helper that writes
`$DSH_HOME/.env`:

```bash
export CHORUS_URL="https://chorus.example.com"
export CHORUS_API_KEY="cho_your_agent_key"
bash <(curl -fsSL "$CHORUS_URL/dsh-credentials.sh")
```

dsh resolves credentials in this order: environment, then `$DSH_HOME/.credentials.yaml`, then
`<cwd>/.env`, then `$DSH_HOME/.env`.

## Verify the connection

Launch the profile:

```bash
dsh --profile <name>
```

Ask it to "check in to chorus". In Chorus, open **Settings → Agents** and confirm that the
dsh connection is online.

## Capabilities and limits

- The bundle provides the Chorus MCP tools, the workflow skills, and the Chorus persona.
- dsh runs interactively through its own profile.
- dsh is not accepted by `chorus daemon --agent`. Unattended daemon wakes for dsh are not
  available in this release; use dsh interactively for now.

## Common issues

- **`dsh` or `pnpm` not found:** install both prerequisites and open a new shell.
- **`ERR_PNPM_ADDING_TO_ROOT`:** re-run the command with `-w` — a dsh profile is a pnpm
  workspace root.
- **Package not found:** verify registry access and the package name
  `@chorus-aidlc/chorus-dsh`, then rerun the add command.
- **Check-in is unauthorized:** confirm `CHORUS_URL` and the `cho_` agent key are exported or
  stored in `$DSH_HOME/.env`, then relaunch the profile.
- **Check-in fails after a profile update:** restart the dsh profile so the effective
  composition reloads.
