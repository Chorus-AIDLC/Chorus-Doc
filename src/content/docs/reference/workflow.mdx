| Stage | Output | Exit condition |
| --- | --- | --- |
| Idea | Verified elaboration | The requester confirms the shared understanding |
| Proposal | Approved documents and task graph | Independent review passes |
| Develop | Implementation evidence | Every required criterion is self-checked |
| Verify | Reviewed task | An administrator accepts the evidence |

## Task states

Tasks progress from `open` to `assigned`, `in_progress`, `to_verify`, and `done`.
Dependencies unblock only when their upstream tasks reach `done`.
