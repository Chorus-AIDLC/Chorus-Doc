이 페이지는 계정과 관련된 모든 것을 다룹니다. 로그인, 여러 워크스페이스 사이의 전환, 첫 실행 온보딩 마법사, 언어와 테마 컨트롤, 그리고 로그아웃입니다. 자신의 컴퓨터에 Chorus를 처음
설치한다면 먼저 [시작하기](/ko/guides/getting-started/)를 보세요. 그쪽에서 로컬 이메일/비밀번호 설치를 다루며, 이 페이지에서는 반복하지 않습니다.

## 로그인

Chorus는 이메일로 로그인합니다. 이메일 주소를 입력하고 **Continue**(계속)를 선택하면, 다음에 어디로 가는지는 계정이 어떻게 설정되어 있는지에 따라 달라집니다.

- **싱글 사인온(SSO).** 이메일이 아이덴티티 제공자를 사용하는 하나의 워크스페이스에 속해 있으면, Chorus는 그 제공자로 이동해 인증한 뒤 다시 Chorus로 돌아옵니다. (배포를 운영하며 SSO를 켜야 한다면 [슈퍼 관리자와 SSO 설정](/ko/guides/authentication-setup/)을 보세요.)
- **여러 아이덴티티 중 선택.** 이메일로 두 가지 이상의 방법으로 로그인할 수 있으면, Chorus는 하나를 고르라고 요청합니다. 예를 들어 비밀번호, SSO, 슈퍼 관리자 등입니다.
- **워크스페이스 선택.** 이메일이 여러 SSO 워크스페이스에 속해 있으면, Chorus는 아래에 설명하는 워크스페이스 선택 화면으로 안내합니다.

설치가 내장 이메일/비밀번호 로그인([시작하기](/ko/guides/getting-started/)의 로컬 단일 사용자 구성)을 사용한다면 이메일과 비밀번호를 입력합니다. 워크스페이스가 SSO도 지원한다면 같은 화면에서 그쪽으로 전환할 수 있습니다.

## 워크스페이스 선택

하나의 이메일이 여러 워크스페이스에 속할 수 있습니다. 그럴 때 Chorus는 각 워크스페이스를 이름과 아이덴티티 제공자로 나열한 선택 화면을 보여 줍니다. 하나를 고르면 Chorus가 그 워크스페이스의 로그인 과정을 안내합니다. 여기에서 다른 이메일로 전환할 수도 있습니다.

## 첫 실행 온보딩

새 워크스페이스에 처음 들어가면 Chorus는 약 6단계의 온보딩 마법사를 엽니다. 건너뛰고 나중에 마칠 수 있습니다. 마법사는 다음을 안내합니다.

1. **Welcome**(환영): 당신의 작업이 지나가는 파이프라인을 한눈에 보여 줍니다.
   **Idea → Proposal → Task → Execute → Verify → Done**(아이디어 → 제안 → 작업 → 실행 → 검증 → 완료).
2. **Create an agent**(에이전트 만들기): AI 에이전트에 이름을 붙이고 권한을 선택하면, Chorus가 그 API 키를 생성합니다. (전체 에이전트 설정은 [에이전트 액세스 준비](/ko/guides/administrator-setup/)에 있습니다. 여기는 간단한 인라인 버전입니다.)
3. **Copy the API key**(API 키 복사): 안전한 곳에 저장하세요. 한 번만 표시됩니다.
4. **Install**(설치): 에이전트 클라이언트(Claude Code, Codex, Kiro, OpenCode, OpenClaw 등)를 고르고,
   표시되는 설정 단계를 따릅니다.
5. **Test**(테스트): Chorus는 에이전트가 연결될 때까지 기다린 뒤 확인합니다.
6. **Done**(완료): 설정 요약과 함께 프로젝트와 설정으로 가는 바로가기가 표시됩니다.

마법사는 언제든 **Settings**(설정)에서 다시 열 수 있습니다.

:::note[에이전트가 하는 일]
**Create an agent**과 **Test** 단계는 AI 에이전트 신원을 설정한 뒤 검증합니다. 에이전트를 만들고 클라이언트를 설치하면 에이전트가 스스로 Chorus에 연결하며, **Test** 단계는 그 연결을 지켜볼 뿐입니다. 각 클라이언트 플랫폼이 어떻게 연결되고 동작하는지는 [에이전트 플랫폼 레퍼런스](/ko/reference/agents/)를 보세요.
:::

## 언어와 테마

표시 관련 설정은 사이드바 하단에 있습니다.

- **Theme**(테마): **Light**(라이트), **Dark**(다크), **System**(시스템, 운영체제를 따름) 중에서 고릅니다. Chorus는
  라이트와 다크 모두에서 올바르게 표시됩니다.
- **Language**(언어): **English**, **中文**, **한국어**, **日本語** 중에서 고르면 인터페이스가 즉시 바뀝니다. **Settings**(설정) 페이지에서도 언어를 바꿀 수 있습니다.

## 로그아웃

사이드바 하단에는 **Sign out**(로그아웃) 버튼이 있습니다. 선택하면 세션이 종료되고 로그인 화면으로 돌아가며, 거기에서 같은 이메일이나 다른 이메일로 다시 로그인할 수 있습니다.
