Chorus 관리자에게 에이전트 API 키를 받은 뒤 이 가이드를 따르세요. Claude Code, Codex 또는 Kiro를 상시 실행 런타임으로 연결해, Chorus가 원격으로 작업을 시작할 수 있게 합니다.

## 시작하기 전에

다음이 필요합니다.

- Chorus URL과 에이전트 API 키.
- Node.js 22 이상.
- 선택한 에이전트 CLI가 설치되고 인증되어 있을 것.
- 승인된 작업 디렉터리 최소 하나.

Chorus 명령을 설치합니다(0.17.2 이상).

```sh
npm install --global @chorus-aidlc/chorus
```

## 에이전트 구성하기

`chorus agents add` 명령 하나로 이 컴퓨터의 에이전트를 Chorus에 연결합니다. 이미 설치된 에이전트를 감지해 각각에 Chorus 플러그인을 설치하고, Chorus URL과 API 키를 한 번만 입력받아 `~/.chorus/daemon.json`에 저장합니다. Claude Code, Codex, DeepSeek Harness는 인증 정보를 각 에이전트의 자체 구성에도 기록하므로, 환경을 따로 설정하지 않아도 대화형 세션이 인증됩니다.

```sh
chorus agents add
```

프롬프트가 나오면 Chorus URL과 API 키를 입력하고 구성할 에이전트를 고릅니다. 이 명령은 멱등적이므로, 에이전트를 추가하거나 플러그인을 새로 고치거나 키를 교체할 때 언제든 다시 실행하면 됩니다. 프롬프트 없이 특정 에이전트를 구성하려면 다음과 같이 실행합니다.

```sh
chorus agents add --agents claude,codex \
  --url https://chorus.example.com --api-key cho_REDACTED --yes
```

:::caution[API 키를 보호하세요]
키가 셸 기록에 남지 않도록 가급적 대화형 프롬프트를 사용하세요. `--api-key`를 꼭 전달해야 한다면 기록을 남기지 않도록 설정된 셸에서 실행하고, 커밋되는 파일이나 지원 요청 메시지에 키를 넣지 마세요.
:::

플러그인 설치 없이 인증 정보만 저장하면 되는 경우(예를 들어 에이전트가 이미 설정된 컴퓨터)에는 대신 `chorus login`을 실행하세요. URL과 키를 검증한 뒤 연결 정보를 `~/.chorus/daemon.json`(모드 `0600`)에 기록합니다.

`chorus agents`와 `chorus mcp`의 모든 옵션은 [chorus CLI](/ko/reference/cli/)를 참고하세요.

## 런타임 시작하기

승인된 작업 디렉터리 하나로 시작합니다.

```sh
chorus daemon --agent claude-code --cwd /path/to/your/project --chorus-only
```

필요하면 `claude-code`를 `codex` 또는 `kiro`로 바꿉니다. `--chorus-only`는 에이전트가 Chorus 도구만 쓰도록 제한합니다. 에이전트에게 로컬 도구 전체를 쓰게 할 의도가 있고 보안상의 영향을 검토한 경우에만 이 옵션을 빼세요.

연결을 확인하는 동안에는 이 명령을 계속 실행해 둡니다. 로그인할 때 데몬이 시작되도록 서비스를 설치하려면 `chorus agents add`에 `--daemon-autostart`를 추가하거나, [Chorus 데몬 운영](/ko/guides/daemon-operations/)을 참고하세요.

## 연결 확인하기

Chorus에서 **설정 → 에이전트**를 열고 에이전트 연결을 살펴봅니다. 다음을 확인하세요.

- 상태가 **온라인**일 것.
- 백엔드가 선택한 CLI와 일치할 것.
- 호스트가 지금 작업 중인 컴퓨터일 것.
- 작업 디렉터리가 승인한 디렉터리일 것.

`chorus agents`를 실행하면 언제든 이 컴퓨터에 구성된 에이전트 목록(이름, UUID, 백엔드. API 키는 출력되지 않음)을 볼 수 있고, `chorus agents remove <name|uuid>`로 에이전트를 제거할 수 있습니다.

확인이 끝나면 `Ctrl+C`로 포그라운드 런타임을 멈춥니다. 다시 로그인하거나 재부팅한 뒤에도 계속 쓸 수 있게 하려면 [Chorus 데몬 운영](/ko/guides/daemon-operations/)으로 이어 가세요.
