Chorus 관리자에게 에이전트 API 키를 받은 뒤에 이 가이드를 사용하세요. Claude Code, Codex, 또는 Kiro를 Chorus가 원격으로 깨울 수 있는 상주 런타임으로 연결합니다.

## 시작하기 전에

필요한 것.

- Chorus URL과 에이전트 API 키.
- Node.js 22 이상.
- 선택한 에이전트 CLI가 설치되고 인증되어 있을 것.
- 승인된 작업 디렉터리 최소 하나.

Chorus 명령을 설치합니다.

```sh
npm install --global @chorus-aidlc/chorus
```

## 연결 저장하기

다음을 실행합니다.

```sh
chorus login
```

프롬프트가 나오면 Chorus URL과 API 키를 입력합니다. Chorus는 인증 정보를 검증하고, 연결을 파일 모드 `0600`으로 `~/.chorus/daemon.json`에 저장합니다.

:::caution[API 키를 보호하세요]
키는 프롬프트에서만 입력하세요. 셸 명령, 셸 기록, 커밋되는 환경 파일, 지원 메시지에 넣지 마세요.
:::

## 런타임 시작하기

승인된 작업 디렉터리 하나로 시작합니다.

```sh
chorus daemon --agent claude-code --cwd /path/to/your/project --chorus-only
```

필요하면 `claude-code`를 `codex` 또는 `kiro`로 바꿉니다. `--chorus-only`는 깨어난 에이전트를 Chorus 도구로 제한합니다. 에이전트가 로컬 도구 전체를 의도적으로 사용하게 하고 그 보안상의 영향을 검토했을 때만 이를 생략하세요.

연결을 확인하는 동안 이 명령은 계속 실행해 둡니다.

## 연결 확인하기

Chorus에서 **설정 → 에이전트**(Settings → Agents)를 열고 에이전트 연결을 살펴봅니다. 다음을 확인합니다.

- 상태가 **온라인**(Online)일 것.
- 백엔드가 선택한 CLI와 일치할 것.
- 호스트가 당신이 운영하는 컴퓨터일 것.
- 작업 디렉터리가 당신이 승인한 디렉터리일 것.
