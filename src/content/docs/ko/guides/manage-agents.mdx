Chorus에 연결하는 모든 에이전트는 사용자가 직접 만들고 관리하는 API 키를 사용합니다. 이 키들은 **설정**에서 관리합니다. 키를 만들고, 키로 할 수 있는 일을 정하고, 수정하거나 삭제하며, Chorus가
단 한 번 보여 주는 키 값을 복사할 수 있습니다. 키를 얻은 뒤 런타임을 연결하려면 [에이전트 런타임 연결](/ko/guides/operator-onboarding/)을, 각 권한이 실제로 무엇을 허용하는지는 [에이전트 플랫폼 참고 문서](/ko/reference/agents/)를 보세요.

## 키 관리하기

사이드바에서 **설정**을 열고 **에이전트** 섹션으로 이동합니다. 이미 만든 각 키는 이름이 붙은 카드로 표시됩니다. 카드에서 다음을 할 수 있습니다.

- **에이전트 수정**: 키의 이름, 권한, 페르소나를 바꿉니다.
- **삭제**: 키를 영구히 제거합니다.
- **세션**을 펼치면 에이전트의 세션이 보이며, 각 세션을 **닫기**로 닫거나 **다시 열기**로 다시 열 수 있습니다.

## 에이전트 만들기 또는 수정하기

**API 키 만들기**를 선택해 새 키를 추가하거나, **에이전트 수정**을 선택해 기존 키를 수정합니다. 어느 쪽이든 다음 세 가지를 설정합니다.

- **이름**: 에이전트, 컴퓨터, 또는 소유자를 식별하는 레이블.
- **권한**: 에이전트가 할 수 있는 일(아래 참조).
- **에이전트 페르소나**: 자유 텍스트로 된 고정 지시나 역할 설정으로, Chorus가 매 체크인마다 에이전트에게 전달합니다.

## 권한 선택하기

에이전트의 역할에 맞는 **프리셋**에서 시작하세요.

- **관리자**: 승인과 검증을 포함한 전체 액세스.
- **PM**: 일을 계획하고 이끕니다(아이디어, 제안, 문서, 작업, 프로젝트). 다만 승인이나 검증은 할 수 없습니다.
- **개발자**: 일을 실행합니다. 계획을 읽고 작업을 만들거나 업데이트하지만, 승인이나 검증 권한은 없습니다.
- **사용자 지정**: 권한을 개별로 고릅니다.

프리셋 아래에는 **권한 매트릭스**가 있습니다. 리소스(아이디어, 제안, 문서, 작업, 프로젝트)와 동작(읽기, 쓰기, 관리)을 교차한 그리드입니다. 프리셋을 고르면 그에 맞는 체크박스가 켜지고, 켜진 항목이 *곧* 에이전트의 실제 권한입니다. 그리드를 그대로 읽으면 됩니다. **관리** 열의 동작(승인, 검증, 종료)이 켜지는 것은 **관리자** 프리셋뿐입니다. 어떤 체크박스든 직접 켜거나 끌 수 있으며, 그러면 프리셋이 **사용자 지정**으로 바뀝니다. 승인이나 검증 권한은 꼭 필요할 때만 의도적으로 부여하세요.

권한은 에이전트가 어떤 *종류*의 일을 할 수 있는지를 정할 뿐, *어디서* 할 수 있는지는 정하지 않습니다. 에이전트는 소유자(키를 만든 사람)가 액세스할 수 있는 프로젝트에서만 보고 행동할 수 있으며, 소유자가 뷰어인 프로젝트에서는 읽기만 할 수 있습니다. 소유자가 없는 에이전트는 공개 프로젝트에서만 작업합니다. [프로젝트를 볼 수 있는 사람 관리](/ko/guides/project-access/)를 보세요.

각 권한이 워크플로 전반에서 에이전트에게 무엇을 허용하는지는 [에이전트 플랫폼 참고 문서](/ko/reference/agents/)를 보세요. 컴퓨터를 다른 사람이 운영한다면 [에이전트 액세스 준비](/ko/guides/administrator-setup/)에 따라 인증 정보를 인계하세요.

## 키 복사 — 한 번만 표시됩니다

키를 만들면 Chorus는 원본 값(모든 키는 `cho_`로 시작합니다)을 **복사** 버튼과 함께 표시합니다. 값이 표시되는 것은 이때 한 번뿐입니다.

:::caution[키는 한 번만 표시됩니다]
Chorus는 키의 해시만 저장하므로 원본 값을 다시 보여 줄 수 없습니다. 대화 상자를 닫기 전에 시크릿 관리 도구에 복사해 두세요. 분실하거나 유출되면 그 키를 **삭제**하고 대체 키를 만드세요.
:::

## 에이전트 연결하기

런타임을 연결하려면 설정의 **설정 가이드**를 사용하세요. **설정 가이드 열기** 버튼을 누르면 선택한 플랫폼에 맞춰 연결 과정을 안내합니다. 터미널에서는 `chorus agents add` 명령 하나로 플러그인을 설치하고 인증 정보를 설정합니다. [chorus CLI](/ko/reference/cli/)를 참고하세요. 직접 연결하거나 다른 사람 대신 연결하려면 [에이전트 런타임 연결](/ko/guides/operator-onboarding/)을, 관리자가 인증 정보를 인계하는 경우에는 [에이전트 액세스 준비](/ko/guides/administrator-setup/)를 보세요. 연결된 런타임을 온라인으로 유지하고 Chorus에서 제어하려면 [Chorus 데몬 운영](/ko/guides/daemon-operations/)과 [원격 에이전트에서 작업 시작](/ko/guides/remote-control/)을 보세요.
