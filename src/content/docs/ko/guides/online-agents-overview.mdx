Chorus는 당신이 온라인으로 유지하는 컴퓨터에서 에이전트 작업을 시작하고 조종할 수 있습니다. 이 페이지는 그 모델을 설명합니다. 온라인 에이전트란 무엇인지, 프로젝트가 어떻게 작업을 하나에 고정하는지, 하나의 대화가 어떻게 하나의 아이디어를 따라가는지, 그리고 어떻게 중단·재개·이어받기를 하는지. 그런 다음, 실제로 각 일을 하는 페이지를 가리킵니다. 이 에이전트들이 실행하는 협업 워크플로는 [AI-DLC 워크플로](/ko/guides/ai-dlc-workflow/)를, 그들이 제공하는 플러그인 명령은 [명령과 스킬 라우팅](/ko/guides/plugin-commands/)을 보세요.

## 온라인 에이전트란

**온라인 에이전트**는 에이전트 API 키로 인증되고 Chorus와의 라이브 연결을 유지하는 `chorus daemon` 프로세스입니다. 그것이 실행되는 동안, Chorus는 그것에 닿아 작업을 시작하거나, 후속 지시를 보내거나, 실행 중인 턴을 중단하거나, 멈춘 턴을 재개할 수 있습니다. 당신이 그 컴퓨터를 건드리지 않고도 말이죠.

각 연결은 세 가지로 주소가 지정됩니다. **에이전트** 신원(API 키), 그것이 실행되는 **호스트**, 그리고 그것이 제공하는 **작업 디렉터리**(`cwd`)입니다. 하나의 데몬은 여러 개의 독립된 에이전트(각자 자신의 키와 신원을 가짐)를 호스팅할 수 있고, 에이전트마다 여러 디렉터리를 제공할 수 있습니다. 등록된 각 `(agent, host, cwd)` 조합은 그 자체로 주소를 지정할 수 있는 대상이 됩니다. Chorus는 각 연결의 존재 여부, 즉 온라인인지 오프라인인지를 그 백엔드, 호스트, 디렉터리와 함께 **설정 → 에이전트**(Settings → Agents)에 표시합니다.

## 프로젝트가 어떻게 디렉터리에 고정되는가

프로젝트는 특정 온라인 에이전트와 작업 디렉터리에 **고정**될 수 있습니다. 일단 고정되면, 그 프로젝트의 UI에서 시작된 에이전트 작업은 같은 연결과 같은 디렉터리로 라우팅되고, 작업 디렉터리 선택기는 숨겨집니다. 매번 대상을 다시 고르지 않습니다. 그 설정을 지정·교체·해제하는 방법은 [프로젝트 생성](/ko/guides/create-a-project/)을 보세요.

## 아이디어당 하나의 세션

직접 아이디어는 하나의 표준 대화를 가지며, 그 session id는 아이디어 자신의 식별자 **그 자체**입니다. 그래서 그 아이디어에 대한 모든 웨이크는 같은 대화에 닿습니다. 다른 작업 디렉터리에서 아이디어를 깨우면, Chorus는 두 번째 대화를 포크하는 대신 그 하나의 세션을 새 디렉터리로 **다시 가리키므로**, 아이디어는 하나의 연속된 기록을 유지합니다.

## 중단, 재개, 이어받기

에이전트가 작업하는 동안, 당신은 현재 턴을 **중단**하거나, 맥락을 더해 멈춘 대화를 **재개**하거나, 복사한 session id로 터미널에서 대화를 **이어받을** 수 있습니다. 이 컨트롤은 새 대화를 시작하는 대신 기존 대화에 작용합니다. [세션 중단과 재개](/ko/guides/session-recovery/)를 보세요.

OpenClaw는 `chorus daemon`이 아니라 OpenClaw 게이트웨이를 통해 연결하므로, 게이트웨이 모델의 연결입니다. [OpenClaw](/ko/reference/agents/openclaw/)를 보세요.

## 각 일을 어디서 하는가

온라인 에이전트 모델의 각 기능에는 그것을 수행하는 한 곳과, 그것을 온전히 기록하는 한 페이지가 있습니다.

| 기능 | 어디서 하는가 | 더 읽기 |
| --- | --- | --- |
| 역방향 제어(중단, 재개) | 대화의 **중단**(Interrupt)과 **재개**(Resume) 컨트롤. 데몬은 이를 `POST /api/daemon/control`로 받음 | [세션 중단과 재개](/ko/guides/session-recovery/) |
| 웨이크와 웨이크 큐 | 프로젝트 항목에서 에이전트 작업을 시작하거나 이어 감. 바쁜 디렉터리에 대한 웨이크는 비워질 때까지 큐에 들어감 | [원격 에이전트에서 작업 시작](/ko/guides/remote-control/) |
| `(agent, host, cwd)` 주소 지정 | 데몬을 시작할 때 각 작업 디렉터리를 등록(반복 가능한 `--cwd`) | [Chorus 데몬 운영](/ko/guides/daemon-operations/) |
| 존재 | **설정 → 에이전트**(Settings → Agents)가 각 연결의 온라인 상태, 백엔드, 호스트, 디렉터리를 표시 | [에이전트 런타임 연결](/ko/guides/operator-onboarding/) |
| 원격 시작 | 온라인 디렉터리를 고르고, 지시를 입력한 뒤 **세션 시작**(Start session) | [원격 에이전트에서 작업 시작](/ko/guides/remote-control/) |
| 임시 "온라인 디렉터리에서 이어 가기" | 새 아이디어 대화 상자의 대화 모드에서 새 아이디어를 온라인 에이전트에 넘김 | [아이디어 기록](/ko/guides/capture-an-idea/) |
| 다중 백엔드(Claude Code, Codex, Kiro) | `--agent`로 연결마다 백엔드를 선택 | [에이전트 플랫폼](/ko/reference/agents/) |
