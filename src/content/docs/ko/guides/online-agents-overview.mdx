Chorus는 온라인으로 유지되는 컴퓨터에서 에이전트 작업을 시작하고 제어할 수 있습니다. 이 페이지는 그 모델을 설명합니다. 온라인 에이전트란 무엇인지, 프로젝트가 작업을 특정 에이전트에 어떻게 고정하는지, 하나의 대화가 어떻게 하나의 아이디어를 따라가는지, 그리고 중단·재개·이어받기를 어떻게 하는지 설명한 뒤, 각 기능을 실제로 사용하는 페이지를 안내합니다. 이 에이전트들이 실행하는 협업 워크플로는 [AI-DLC 워크플로](/ko/guides/ai-dlc-workflow/)를, 에이전트가 제공하는 플러그인 명령은 [명령과 스킬 라우팅](/ko/guides/plugin-commands/)을 보세요.

## 온라인 에이전트란

**온라인 에이전트**는 에이전트 API 키로 인증되고 Chorus와의 라이브 연결을 유지하는 `chorus daemon` 프로세스입니다. 데몬이 실행되는 동안에는 사용자가 그 컴퓨터를 직접 조작하지 않아도, Chorus가 데몬을 통해 작업을 시작하거나, 후속 지시를 보내거나, 실행 중인 턴을 중단하거나, 멈춘 턴을 재개할 수 있습니다.

각 연결의 주소는 세 가지 요소로 정해집니다. **에이전트** 신원(API 키), 에이전트가 실행되는 **호스트**, 그리고 에이전트가 담당하는 **작업 디렉터리**(`cwd`)입니다. 하나의 데몬은 독립된 에이전트(각자 자신의 키와 신원을 가짐)를 여러 개 호스팅할 수 있고, 에이전트마다 여러 디렉터리를 담당할 수 있습니다. 등록된 각 `(agent, host, cwd)` 조합은 각각 독립적으로 지정할 수 있는 대상이 됩니다. Chorus는 각 연결의 온라인 상태, 즉 온라인인지 오프라인인지를 그 백엔드, 호스트, 디렉터리와 함께 **설정 → 에이전트**(Settings → Agents)에 표시합니다.

## 프로젝트가 어떻게 디렉터리에 고정되는가

프로젝트는 특정 온라인 에이전트와 작업 디렉터리에 **고정**될 수 있습니다. 일단 고정되면, 그 프로젝트의 UI에서 시작된 에이전트 작업은 같은 연결과 같은 디렉터리로 라우팅되고, 작업 디렉터리 선택기는 숨겨지므로 매번 대상을 다시 고를 필요가 없습니다. 그 설정을 지정·교체·해제하는 방법은 [프로젝트 생성](/ko/guides/create-a-project/)을 보세요.

## 아이디어당 하나의 세션

각 아이디어에는 하나의 대화만 있으므로, 그 아이디어에서 에이전트 작업을 시작할 때마다 같은 대화로 이어집니다. 다른 작업 디렉터리에서 그 아이디어의 작업을 시작하면, Chorus는 두 번째 대화를 시작하는 대신 그 하나의 세션을 새 디렉터리로 **옮기므로**, 아이디어는 하나의 연속된 기록을 유지합니다.

## 중단, 재개, 이어받기

에이전트가 작업하는 동안 현재 턴을 **중단**하거나, 맥락을 더해 멈춘 대화를 **재개**하거나, 복사한 세션 ID로 터미널에서 대화를 **이어받을** 수 있습니다. 이 컨트롤은 새 대화를 시작하는 대신 기존 대화에 작용합니다. [세션 중단과 재개](/ko/guides/session-recovery/)를 보세요.

OpenClaw는 `chorus daemon`이 아니라 OpenClaw 게이트웨이를 통해 연결하는 게이트웨이 모델입니다. [OpenClaw](/ko/reference/agents/openclaw/)를 보세요.

## 각 일을 어디서 하는가

온라인 에이전트 모델의 각 기능마다 사용하는 곳이 한 군데, 자세히 설명하는 페이지가 하나씩 있습니다.

| 기능 | 어디서 하는가 | 더 읽기 |
| --- | --- | --- |
| 중단과 재개 | 대화의 **중단**(Interrupt)과 **재개**(Resume) 컨트롤 | [세션 중단과 재개](/ko/guides/session-recovery/) |
| 작업 시작(바쁠 때는 대기열) | 프로젝트 항목에서 에이전트 작업을 시작하거나 이어 감. 사용 중인 디렉터리에 대한 요청은 디렉터리가 빌 때까지 대기열에 들어감 | [원격 에이전트에서 작업 시작](/ko/guides/remote-control/) |
| `(agent, host, cwd)` 주소 지정 | 데몬을 시작할 때 각 작업 디렉터리를 등록(반복 가능한 `--cwd`) | [Chorus 데몬 운영](/ko/guides/daemon-operations/) |
| 온라인 상태 | **설정 → 에이전트**(Settings → Agents)가 각 연결의 온라인 상태, 백엔드, 호스트, 디렉터리를 표시 | [에이전트 런타임 연결](/ko/guides/operator-onboarding/) |
| 원격 시작 | 온라인 디렉터리를 고르고, 지시를 입력한 뒤 **세션 시작**(Start session) | [원격 에이전트에서 작업 시작](/ko/guides/remote-control/) |
| 즉석에서 "온라인 디렉터리에서 이어 가기" | 새 아이디어 대화 상자의 대화 모드에서 새 아이디어를 온라인 에이전트에 넘김 | [아이디어 기록](/ko/guides/capture-an-idea/) |
| 다중 백엔드(Claude Code, Codex, Kiro, Pi, DeepSeek Harness) | `--agent`로 연결마다 백엔드를 선택 | [에이전트 플랫폼](/ko/reference/agents/) |
