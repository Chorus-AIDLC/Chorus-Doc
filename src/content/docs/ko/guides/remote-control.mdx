에이전트 런타임이 이미 **온라인**(Online)이고, 그 컴퓨터에서 Chorus가 작업을 시작하게 하고 싶을 때 원격 시작을 사용합니다.

## 런타임 선택하기

작업을 시작하기 전에 다음을 확인합니다.

- 에이전트 신원이 그 프로젝트에 의도한 것인지.
- 연결이 **온라인**(Online)인지.
- 호스트가 기대하는 컴퓨터인지.
- 작업 디렉터리에 변경하려는 프로젝트가 들어 있는지.

프로젝트나 작업이 특정 연결에 고정되어 있으면, Chorus는 그 호스트와 작업 디렉터리를 계속 사용합니다. 그 연결이 오프라인이면 복구하거나 다른 대상을 의도적으로 선택하세요. Chorus는 고정된 작업을 소리 없이 옮기지 않습니다.

:::caution[작업 디렉터리가 실행 컨텍스트를 정의합니다]
에이전트는 선택된 디렉터리에 대한 접근 권한과, 그 데몬에 구성된 권한 모드로 실행됩니다. 지시를 보내기 전에 대상을 확인하세요.
:::

## 세션 시작하기

1. 에이전트가 처리하길 원하는 프로젝트 항목을 엽니다.
2. 에이전트 작업을 시작하거나 이어 가는 액션을 선택합니다.
3. 온라인 작업 디렉터리를 선택합니다.
4. 기대하는 결과와 제약을 포함해, 구체적인 지시를 입력합니다.
5. **세션 시작**(Start session)을 선택합니다.

## 결과 관찰하기

대화를 열어 현재 턴과 에이전트 출력을 따라갑니다. 자리를 비우기 전에, 세션이 선택한 연결에서 시작되었는지 확인합니다.

세션이 시작되지 않으면, 먼저 대상이 아직 온라인인지 확인합니다. 전달 실패에는 [에이전트 연결 문제 해결](/ko/guides/troubleshooting/)을 사용하세요. 세션이 이미 시작되었으나 개입이 필요할 때는 [세션 중단과 재개](/ko/guides/session-recovery/)를 사용하세요.
