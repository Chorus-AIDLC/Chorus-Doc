당신이 Chorus를 관리하지만 에이전트를 실행하는 컴퓨터는 다른 사람이 운영하는 경우 이 가이드를 사용하세요. 자신의 컴퓨터를 연결한다면 앱 안의 **Setup Guide**가 대개 더 빠릅니다.

## 인증 정보 만들기

1. **설정**(Settings)을 열고 **에이전트**(Agents)로 이동합니다.
2. **API 키 만들기**(Create API Key)를 선택합니다.
3. 에이전트와 그 소유자 또는 컴퓨터를 식별할 수 있는 이름을 입력합니다.
4. 에이전트가 수행할 작업에 가장 가까운 프리셋을 선택합니다.
5. 개별 권한을 검토하고, 에이전트에 필요 없는 것은 제거합니다.
6. 키를 만들고 즉시 보관합니다.

구현 작업에는 **Developer** 프리셋으로 시작하세요. 제안, 문서, 프로젝트, 관리 액세스는 에이전트에 배정된 워크플로가 필요로 할 때만 추가합니다.

:::caution[API 키는 한 번만 표시됩니다]
`cho_`로 시작하는 값은 비밀번호처럼 다루세요. 시크릿 매니저나 승인된 다른 인증 정보 저장소에 보관합니다. 노출되었다면 **설정 → 에이전트**(Settings → Agents)에서 키를 폐기하고 대체 키를 만드세요.
:::

## 운영자에게 필요한 것 전달하기

승인된 안전한 경로로 다음을 보냅니다.

- Chorus URL.
- 에이전트 이름과 API 키.
- 선택한 플랫폼(예: Claude Code, Codex, Kiro).
- 에이전트가 작업해도 되는 디렉터리.
- 부여한 권한.

실제 API 키를 티켓, 채팅방, 스크린샷, 셸 명령, 소스 리포지토리에 두지 마세요.

## 액세스 확인하기

운영자에게 [에이전트 런타임 연결](/ko/guides/operator-onboarding/)의 단계를 따르게 합니다. 완료되면 다음을 확인합니다.

1. **설정 → 에이전트**(Settings → Agents)를 엽니다.
2. 해당 에이전트를 찾아 그 연결 세부 정보를 엽니다.
3. 상태가 **온라인**(Online)인지 확인합니다.
4. 백엔드, 호스트, 작업 디렉터리가 의도한 컴퓨터와 일치하는지 확인합니다.

연결이 온라인이 되지 않으면 [에이전트 연결 문제 해결](/ko/guides/troubleshooting/)을 사용하세요. 더 이상 사용하지 않는 인증 정보는 폐기합니다. 컴퓨터나 운영자가 바뀐 뒤에는 특히 잊지 마세요.
