각 단계는 산출물을 만들어 내며, 종료 조건을 충족하면 끝납니다.

| 단계 | 산출물 | 종료 조건 |
| --- | --- | --- |
| 아이디어 | 검증된 요구사항 구체화 결과 | 요청자가 공통된 이해를 확인함 |
| 제안 | 승인된 문서와 작업 그래프 | 독립적인 검토를 통과함 |
| 개발 | 구현 증거 | 모든 필수 기준이 자체 확인됨 |
| 검증 | 검토된 작업 | 관리자가 증거를 받아들임 |

## 작업 상태

작업은 `open`에서 `assigned`, `in_progress`, `to_verify`, `done`으로 진행됩니다.
다른 작업에 의존하는 작업은 선행 작업이 모두 `done`에 도달해야 차단이 풀립니다.
