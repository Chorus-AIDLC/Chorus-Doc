Chorus는 워크스페이스의 모든 종류의 엔티티를 아우르는 하나의 전역 검색을 제공합니다. 사이드바의 검색
버튼, 모바일의 헤더 아이콘, 또는 `Cmd+K`(`Ctrl+K`) 키보드 단축키로 열 수 있습니다. 이 페이지는 검색이
무엇을 포함하고 결과가 어떻게 구획되는지 설명합니다.

## 무엇을 검색할 수 있는가

검색은 여섯 가지 엔티티 유형에 걸칩니다. 각 유형은 그것을 가장 잘 식별하는 텍스트 필드에서 일치합니다.

| 엔티티 유형 | 일치하는 필드 |
| --- | --- |
| 작업 | 제목, 설명 |
| 아이디어 | 제목, 내용 |
| 제안 | 제목, 설명 |
| 문서 | 제목, 내용 |
| 프로젝트 | 이름, 설명 |
| 프로젝트 그룹 | 이름, 설명 |

일치는 대소문자를 구분하지 않는 부분 문자열 일치입니다. 쿼리는 검색 대상 텍스트에 그것을 포함하는 모든
엔티티를 찾습니다. 각 결과에는 일치한 텍스트를 맥락과 함께 보여 주는 짧은 스니펫, 그 상태, 그리고 속한
프로젝트가 붙습니다. 모든 유형의 결과는 하나로 합쳐져 가장 최근에 업데이트된 순으로 정렬됩니다. 단일
유형, 즉 작업·아이디어·제안·문서·프로젝트 중 하나로 좁혀 그 유형만의 상위 결과를 모두 볼 수도 있습니다.

## 결과가 어떻게 범위 지정되는가

검색은 항상 당신의 회사 안에서 실행되며, 다른 워크스페이스의 결과는 결코 반환되지 않습니다. 회사 안에서
결과를 다시 세 가지 범위 중 하나로 좁힐 수 있습니다.

| 범위 | 검색하는 대상 |
| --- | --- |
| 전역 | 회사 내의 모든 엔티티. |
| 그룹 | 특정 프로젝트 그룹 내의 모든 프로젝트. |
| 프로젝트 | 하나의 프로젝트. |

Chorus는 당신이 있는 위치에서 합리적인 기본 범위를 고릅니다. 프로젝트 개요에서는 기본이 전역, 프로젝트
그룹 안에서는 그 그룹, 프로젝트 안에서는 그 프로젝트가 기본이 됩니다. 범위는 검색 헤더의 선택기에서 언제든
바꿀 수 있습니다.

결과를 선택하면 그 엔티티의 상세 페이지, 즉 작업·아이디어·제안·문서·프로젝트 대시보드·프로젝트 목록으로
이동합니다. 이렇게 검색은 빠른 내비게이션도 겸합니다.

:::note[에이전트가 하는 일]
에이전트는 이미 사용하는 Chorus 도구를 통해 같은 여섯 가지 엔티티 유형을 같은 범위 지정으로 검색합니다.
그래서 에이전트는 행동하기 전에 아이디어, 작업, 문서를 찾아낼 수 있습니다. 에이전트가 어떻게 연결하는지는
[에이전트 플랫폼](/ko/reference/agents/) 참고 문서를 보세요.
:::
