# DeepSeek Harness

DeepSeek Harness (dsh)는 제1자 npm 번들 `@chorus-aidlc/chorus-dsh`를 통해 Chorus에 연결됩니다. 이 번들은 Chorus MCP 도구, 워크플로 스킬, 페르소나를 dsh 프로필에 추가합니다. dsh는 대화식으로 사용합니다. dsh의 무인 daemon wake는 이번 릴리스에서는 제공되지 않습니다.

설치 전에 `0.1.0-rc.7` 이상의 dsh(및 `pnpm`)를 사용하고 [에이전트 액세스 준비](/ko/guides/administrator-setup/)에 따라 에이전트 키를 만드세요.

## 번들 설치

Chorus 번들을 dsh 프로필에 추가합니다. 명령의 `name` 자리표시자를 사용할 프로필 이름으로 바꾸세요. dsh 프로필은 pnpm 워크스페이스 루트이므로 `-w`가 필요합니다:

```bash
dsh plugin --profile <name> add @chorus-aidlc/chorus-dsh -w
```

## 자격 증명 저장

dsh는 도구 하위 프로세스에서 자격 증명 형태의 변수를 제거하므로, Chorus URL과 에이전트 키를 dsh가 해석하는 위치에 저장하세요. Chorus 서버는 `$DSH_HOME/.env`에 기록하는 도우미를 제공합니다:

```bash
export CHORUS_URL="https://chorus.example.com"
export CHORUS_API_KEY="cho_your_agent_key"
bash <(curl -fsSL "$CHORUS_URL/dsh-credentials.sh")
```

dsh는 다음 순서로 자격 증명을 해석합니다: 환경 변수 → `$DSH_HOME/.credentials.yaml` → `<cwd>/.env` → `$DSH_HOME/.env`.

## 연결 확인

프로필을 실행합니다:

```bash
dsh --profile <name>
```

"check in to chorus"라고 요청하세요. Chorus에서 **설정 → 에이전트**를 열고 dsh 연결이 온라인인지 확인합니다.

## 기능과 제한

- 번들은 Chorus MCP 도구, 워크플로 스킬, Chorus 페르소나를 제공합니다.
- dsh는 자체 프로필을 통해 대화식으로 동작합니다.
- dsh는 `chorus daemon --agent`로 받아들여지지 않습니다. dsh의 무인 daemon wake는 이번 릴리스에서 제공되지 않으므로 당분간 대화식으로 사용하세요.

## 자주 발생하는 문제

- **`dsh` 또는 `pnpm`을 찾을 수 없음:** 두 전제 도구를 설치하고 새 셸을 엽니다.
- **`ERR_PNPM_ADDING_TO_ROOT`:** `-w`를 붙여 명령을 다시 실행하세요. dsh 프로필은 pnpm 워크스페이스 루트입니다.
- **패키지를 찾을 수 없음:** 레지스트리 액세스와 패키지 이름 `@chorus-aidlc/chorus-dsh`를 확인한 뒤 추가 명령을 다시 실행합니다.
- **체크인이 승인되지 않음:** `CHORUS_URL`과 `cho_` 에이전트 키가 내보내졌거나 `$DSH_HOME/.env`에 저장되었는지 확인한 뒤 프로필을 다시 시작합니다.
- **프로필 업데이트 후 체크인 실패:** dsh 프로필을 재시작하여 유효한 composition을 다시 로드합니다.
