# OpenCode

OpenCode 지원은 Chorus 팀이 아니라 커뮤니티가
[etnperlong/opencode-chorus](https://github.com/etnperlong/opencode-chorus)에서 유지합니다.
OpenCode 또는 Chorus를 업그레이드할 때는 해당 프로젝트의 호환성 안내를 확인하세요.

설치 전에 [에이전트 액세스 준비](/ko/guides/administrator-setup/)에 따라 에이전트 키를
만드세요.

## 통합 설치

`chorus` CLI로 커뮤니티 통합을 설치합니다.

```bash
npm install --global @chorus-aidlc/chorus
chorus agents add --agents opencode
```

`chorus agents add`는 `opencode plugin opencode-chorus -g`를 실행하여 커뮤니티 패키지를 전역
`~/.config/opencode/opencode.json`에 등록하고, OpenCode는 다음에 시작할 때 이를 내려받습니다.
OpenCode는 셸에서 인증 정보를 읽으므로, OpenCode를 시작하는 환경에서 인증 정보를 설정합니다.

```bash
export CHORUS_URL="https://chorus.example.com"
export CHORUS_API_KEY="cho_REDACTED"
```

## 연결 확인

`opencode`를 실행하고 `check in to chorus`를 요청합니다. 응답이 예상한 에이전트 신원과 권한을
보여 주는지 확인합니다. 이는 커뮤니티 MCP 연결을 확인하는 것이며 제1자 지원을 의미하지 않습니다.

## 기능과 제한

- 커뮤니티 플러그인은 Chorus MCP 도구, 스킬, 그리고 훅을 제공합니다.
- OpenCode는 Chorus 데몬 백엔드가 아닙니다.
- Chorus는 OpenCode에 대해 원격 시작, 대화 기록 제어, 중단, 세션 복구를 보장하지 않습니다.
- 호환성과 대화 복구는 OpenCode 및 커뮤니티 플러그인에 달려 있습니다.

## 자주 발생하는 문제

- **플러그인이 로드되지 않음:** `~/.config/opencode/opencode.json`을 확인하고, 필요하면 커뮤니티
  패키지 캐시를 지운 뒤 OpenCode를 재시작합니다.
- **환경 변경이 무시됨:** `CHORUS_URL`과 `CHORUS_API_KEY`가 설정된 셸에서 OpenCode를 시작합니다.
- **체크인이 승인되지 않음:** 에이전트 키를 교체하고 업데이트된 환경에서 OpenCode를
  재시작합니다.
- **업그레이드 후 동작이 바뀜:** 커뮤니티 프로젝트의 릴리스와 이슈를 확인합니다.

일반적인 키 문제는 [문제 해결](/ko/guides/troubleshooting/)을 참고하세요.
