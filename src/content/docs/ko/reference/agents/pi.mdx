# Pi

Pi 통합은 제1자이지만 현재는 고급 평가용으로 의도되어 있습니다. 독립 패키지로 배포되지 않으며,
설치하려면 Chorus 리포지토리의 로컬 체크아웃이 필요합니다. 대부분의 최종 사용자는 다른
[지원 플랫폼](/ko/reference/agents/)을 선택하는 것이 좋습니다.

설치 전에 [에이전트 액세스 준비](/ko/guides/administrator-setup/)에 따라 에이전트 키를
만드세요.

## 소스 체크아웃에서 설치

Chorus 체크아웃의 루트에서 실행합니다.

```bash
pi install npm:pi-mcp-adapter
pi install npm:@narumitw/pi-subagents
pi install ./packages/chorus-pi
mkdir -p ~/.pi/agent/agents
cp packages/chorus-pi/agents/*.md ~/.pi/agent/agents/
```

Pi는 모노레포 Git URL에서 패키지 하위 디렉터리를 선택할 수 없으므로, Chorus 리포지토리 URL을
직접 설치해도 이 통합은 설치되지 않습니다.

프로젝트의 `.mcp.json`을 다음과 같이 구성합니다.

```text
URL: https://chorus.example.com/api/mcp
Authorization: Bearer cho_REDACTED
```

`.mcp.json`에는 에이전트 키가 들어 있으므로 버전 관리에 포함하지 마세요.

## 연결 확인

Pi를 재시작하고 `/mcp`를 확인한 뒤 Pi에 `chorus_checkin` 호출을 요청합니다. 응답이 예상한
에이전트 신원과 권한을 보여 주는지 확인합니다. 첫 턴에서도 Chorus 플러그인이 활성 상태라고
보고되어야 합니다.

## 기능과 제한

- 패키지는 Chorus MCP 도구, 워크플로 스킬, 검토 에이전트, 그리고 Pi 훅을 제공합니다.
- Pi는 Chorus 데몬 백엔드가 아닙니다.
- Chorus는 Pi 세션을 원격으로 시작, 중단, 재개할 수 없습니다.
- 로컬 대화 복구는 Pi 자체 세션 기능을 사용합니다.

## 자주 발생하는 문제

- **MCP 서버가 없음:** `.mcp.json`을 프로젝트 루트에 두거나 `/mcp setup`을 실행합니다.
- **스킬이 없음:** 설치 후 `/reload`를 실행합니다.
- **검토 에이전트가 없음:** `pi-subagents`가 설치되어 있고 동봉된 에이전트 파일이 복사되었는지
  확인합니다.
- **연결이 승인되지 않음:** `.mcp.json`의 에이전트 키를 교체한 뒤 Pi를 재시작합니다.

일반적인 연결 문제는 [문제 해결](/ko/guides/troubleshooting/)을 참고하세요.
