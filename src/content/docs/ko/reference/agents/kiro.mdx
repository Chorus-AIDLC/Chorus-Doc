# Kiro

Kiro CLI에는 도구, 워크플로 스킬, 에이전트, 훅을 갖춘 제1자 Chorus 통합이 있습니다. Kiro는
지원되는 Chorus 데몬 백엔드이기도 합니다.

설치 전에 Kiro CLI v2를 설치하고 [에이전트 액세스 준비](/ko/guides/administrator-setup/)에
따라 에이전트 키를 만드세요.

## 통합 설치

사용자 전체로 설치하려면:

```bash
export CHORUS_URL="https://chorus.example.com"
export CHORUS_API_KEY="cho_REDACTED"
curl -fsSL "$CHORUS_URL/install-kiro.sh" | bash
```

현재 워크스페이스에만 설치하려면:

```bash
curl -fsSL "$CHORUS_URL/install-kiro.sh" | bash -s -- --workspace
```

설치 후 Kiro를 재시작합니다.

## 원격 시작 활성화

대화식 Kiro 세션에서만 Chorus를 사용한다면 이 섹션을 건너뛰세요. 그렇지 않다면
[런타임 연결](/ko/guides/operator-onboarding/)에 따라 백엔드로 `kiro`를 선택합니다.
[데몬 운영](/ko/guides/daemon-operations/)으로 온라인 상태를 유지하기 전에, 포그라운드에서
연결을 확인하세요.

## 연결 확인

`kiro-cli --agent chorus`를 실행한 뒤 Kiro에 `check in to chorus`를 요청합니다. 응답이 예상한
에이전트 신원과 권한을 보여 주는지 확인합니다. `/chorus-idea`를 실행해 Chorus 스킬을 사용할 수
있는지 확인합니다.

데몬 모드에서는 Chorus의 **설정 → 에이전트**를 열고 예상한 호스트와 작업 디렉터리가 온라인인지
확인합니다.

## 기능과 제한

- 통합은 Chorus MCP 도구, 워크플로 스킬, 검토 에이전트, 그리고 훅을 제공합니다.
- 데몬 모드는 원격 시작, 후속 지시, 중단, 재개를 지원합니다.
- 워크스페이스 구성이 사용자 전체 Kiro 구성보다 우선합니다.
- 원격 작업은 로컬 사용자의 접근 권한을 상속합니다. 신뢰하는 작업 디렉터리만 등록하세요.

공통 운영 절차는 [원격 제어](/ko/guides/remote-control/)와
[세션 복구](/ko/guides/session-recovery/)를 사용하세요.

## 터미널에서 재개하기

자신의 터미널에서 진행 중인 대화를 넘겨받으려면, 채팅 UI에서 해당 세션 ID를 복사한 뒤
(대화 기록 헤더의 **Copy session ID**), 그 대화의 작업 디렉터리에서 실행합니다.

```bash
kiro-cli chat --resume-id <sessionId>
```

복사한 ID는 Chorus가 세션을 재개할 때 Kiro CLI에 전달하는 것과 같은 ID입니다. 전체 흐름은
[세션 중단과 재개](/ko/guides/session-recovery/#터미널에서-이어받기)를 참고하세요.

## 자주 발생하는 문제

- **Kiro CLI를 찾을 수 없음:** Kiro CLI v2를 설치하고 설치 프로그램을 다시 실행합니다.
- **스킬이 없음:** 워크스페이스 설치가 사용자 전체 설치를 덮어쓰고 있지 않은지 확인한 뒤 Kiro를
  재시작합니다.
- **체크인이 승인되지 않음:** Kiro를 시작하는 셸에서 에이전트 키를 사용할 수 있는지 확인하거나,
  데몬 모드에서는 `chorus login`을 다시 실행합니다.
- **데몬이 오프라인:** `chorus daemon status`를 실행한 뒤
  [문제 해결](/ko/guides/troubleshooting/)을 참고합니다.
