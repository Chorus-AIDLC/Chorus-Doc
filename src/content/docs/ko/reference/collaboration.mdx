Chorus는 논의를 작업에 붙어 있게 합니다. 당신은 엔티티에 댓글을 달고, 특정한 사람이나 에이전트를
@멘션하며, 관련된 일이 일어날 때 알림을 받아 협업합니다. 이 페이지는 각 표면과 그것들이 어떻게
연결되는지 설명합니다.

## 댓글

댓글을 달 수 있는 엔티티는 네 가지입니다. **아이디어(Idea)**, **제안(Proposal)**, **작업(Task)**,
그리고 **문서(Document)** 입니다. 댓글은 최신순으로 정렬되고 점진적으로 불러와지므로, 긴 논의도 읽기
좋게 유지됩니다. 각 댓글은 작성자, 즉 사용자 또는 에이전트를 기록하며, 사람과 에이전트는 같은 스레드에
댓글을 달 수 있습니다.

댓글이 추가되면, Chorus는 그 엔티티에 연결된 사람과 에이전트에게 알리되, 댓글 작성자 본인에게는 결코
알리지 않습니다.

| 댓글이 달린 엔티티 | 알림을 받는 대상 |
| --- | --- |
| 작업 | 작업의 담당자와 작성자. |
| 아이디어 | 아이디어의 담당자와 작성자. |
| 제안 | 제안의 작성자. |
| 문서 | 문서의 작성자. |

## @멘션

댓글에서 `@`를 입력하면 특정한 사람이나 에이전트를 이름으로 지목할 수 있습니다. 멘션은 단순한 문자열이
아니라 구체적인 수신자, 즉 사용자나 에이전트로 해석되므로, 표시 이름이 모호하더라도 항상 올바른 대상에게
알림이 갑니다. 하나의 댓글은 최대 열 개의 멘션을 담을 수 있습니다.

**에이전트**를 멘션하는 것은 알림에 그치지 않습니다. 멘션한 대상 엔티티에서 행동하도록 그 에이전트를
깨울 수 있습니다. 연결한 에이전트를 데몬으로 실행하고 있을 때는, 멘션을 특정 실행 중 인스턴스(어떤 호스트와
작업 디렉터리)에 고정할 수 있어 후속 응답이 의도한 곳에 정확히 도달합니다.

멘션은 항상 멘션된 대상에게(그 알림 설정에 따라) 알립니다. 다만 자기 자신을 멘션하는 것은 무시됩니다.
멘션은 댓글의 상위 엔티티에 붙어 저장되므로, 그 알림은 댓글이 있는 아이디어, 제안, 작업, 문서로 곧장
연결됩니다.

## 알림

알림은 두 가지 출처에서 자동으로 생성됩니다.

- **@멘션**: 사용자나 에이전트를 멘션하면 그 대상에게 `mentioned` 알림이 생성됩니다.
- **활동(Activity)**: 엔티티에서의 중요한 동작은 그것에 연결된 사람과 에이전트에게 알림을 생성합니다.
  예를 들어 작업 배정, 상태 변경, 검증 제출, 검증, 제안의 승인이나 거부, 아이디어를 가져감, 요구사항
  구체화의 질문이나 답변, 그리고 댓글 추가입니다.

각 수신자는 자신의 알림 설정으로 어떤 범주를 받을지 조정합니다. 범주는 다음과 같습니다.

| 범주 | 발생 시점 |
| --- | --- |
| 작업 배정됨 | 당신이 작업에 배정됨. |
| 작업 상태 변경됨 | 당신과 연결된 작업의 상태가 바뀜. |
| 작업 검증 | 작업이 검증에 제출되거나 검증됨. |
| 작업 다시 열림 | 검증 대기 중인 작업이 진행 중으로 되돌려짐. |
| 제안 제출됨 | 제안이 검토에 제출됨. |
| 제안 승인됨 | 당신이 작성한 제안이 승인됨. |
| 제안 거부됨 | 당신이 작성한 제안이 거부됨. |
| 아이디어를 가져감 | 당신이 만들거나 담당한 아이디어를 누군가 가져감. |
| 댓글 추가됨 | 당신과 연결된 엔티티에 댓글이 추가됨. |
| 요구사항 구체화 요청됨 | 어떤 구체화 라운드가 당신의 답변을 필요로 함. |
| 요구사항 구체화 답변됨 | 당신이 기다리던 구체화 질문에 답이 달림. |
| 멘션됨 | 누군가 당신을 @멘션함. |

수신자가 어떤 범주를 껐다면 그 알림은 건너뜁니다. 알림은 읽음으로 표시할 수 있고 당신의 회사 범위로
한정되므로, 다른 워크스페이스의 활동을 보는 일은 결코 없습니다.

:::note[에이전트가 하는 일]
아이디어나 작업에서의 @멘션, 또는 단계를 앞으로 나아가게 하는 동작은 연결된 에이전트를 깨워 응답하게
할 수 있습니다. 제안을 초안하거나, 다음 요구사항 구체화 라운드를 진행하거나, 배정된 작업을 가져가는 식의
응답입니다. 관찰되는 효과는 하나의 답글 또는 하나의 상태 변경입니다. 연결이 어떻게 설정되는지는
[에이전트 플랫폼](/ko/reference/agents/) 참고 문서를 보세요.
:::
