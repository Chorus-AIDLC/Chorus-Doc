이 문서에서 쓰는 용어의 빠른 참조입니다. 각 항목에는 제품에서 쓰는 이름, 한 줄 정의, 그리고 자세한
설명이 있는 페이지 링크가 있습니다. 각 엔티티가 거쳐 가는 상태는 [엔티티 라이프사이클 참고](/ko/reference/lifecycle/)를,
각 단계가 어떻게 인계하는지는 [워크플로 참고](/ko/reference/workflow/)를 보세요.

## 핵심 엔티티

<div class="table-scroll" role="region" aria-label="핵심 엔티티 용어" tabindex="0">

  | 용어 | 정의 |
  | --- | --- |
  | **Idea**(아이디어) | 파이프라인에 들어오는 요청. 제안 초안을 작성하기 전에 요구사항 구체화를 거친다. [아이디어 기록](/ko/guides/capture-an-idea/) 참조. |
  | **Proposal**(제안) | 문서 초안과 작업 초안의 검토용 컨테이너. 승인하면 실제 문서와 작업이 생성된다. [제안 검토](/ko/guides/review-a-proposal/) 참조. |
  | **Task**(작업) | 우선순위, 추정치, 수락 기준, 의존 관계를 가진 작업 단위. 완료 전에 검증된다. [작업 실행](/ko/guides/run-tasks/)과 [검증과 완료](/ko/guides/verify-and-complete/) 참조. |
  | **Document**(문서) | PRD, 명세, 설계, 리포트 같은 작성된 산출물. 제안의 문서 초안에서 생성되어 프로젝트에 붙는다. [제안 검토](/ko/guides/review-a-proposal/) 참조. |
  | **Reference**(참고 자료) | 아이디어, 제안, 작업에 붙이는 외부 근거(문서, 저장소, issue/PR, 논문/블로그)의 링크. URL과 메모가 저장되며 페이지 자체는 저장되지 않는다. [참고 자료 첨부하기](/ko/guides/references/) 참조. |
  | **Project**(프로젝트) | 한 프로젝트의 아이디어, 제안, 문서, 작업을 담는 단위. [프로젝트 생성](/ko/guides/create-a-project/) 참조. |
  | **Project group**(프로젝트 그룹) | 관련 프로젝트를 하나의 제목 아래 정리하는 폴더. [프로젝트 생성](/ko/guides/create-a-project/) 참조. |
  | **Private project / group**(비공개 프로젝트/그룹) | 멤버와 그들이 소유한 에이전트만 볼 수 있는 프로젝트나 그룹(프로젝트의 경우 그 그룹의 멤버도 포함). 워크스페이스의 다른 모든 사람에게는 보이지 않는다. [프로젝트를 볼 수 있는 사람 관리](/ko/guides/project-access/) 참조. |
  | **Viewer / Editor / Admin**(뷰어/편집자/관리자) | 멤버가 가질 수 있는 역할. 뷰어는 읽기만 할 수 있다(비공개 프로젝트에만 해당하며, 공개 프로젝트에서는 모든 사람이 최소한 편집자다). 편집자는 제안 승인과 작업 검증을 포함해 읽고 쓸 수 있다. 관리자는 여기에 더해 공개 범위를 바꾸고 멤버를 관리할 수 있다. [프로젝트를 볼 수 있는 사람 관리](/ko/guides/project-access/) 참조. |

</div>

## 요구사항 구체화와 아이디어 형태

<div class="table-scroll" role="region" aria-label="요구사항 구체화와 아이디어 형태 용어" tabindex="0">

  | 용어 | 정의 |
  | --- | --- |
  | **Acceptance criterion**(수락 기준) | 작업이 검증되기 위해 충족해야 하는, 검증 가능한 하나의 조건. [검증과 완료](/ko/guides/verify-and-complete/) 참조. |
  | **Elaboration round**(요구사항 구체화 라운드) | 아이디어의 요구사항을 명확히 하는, 구조화된 한 차례의 질문과 답변. 요구사항 구체화는 해결될 때까지 라운드를 반복한다. [아이디어 기록](/ko/guides/capture-an-idea/) 참조. |
  | **Theme**(테마 아이디어) | 관련 자식 아이디어를 공통된 방향 아래 묶기만 하는 아이디어. 테마 자체는 제안이 될 수 없다. [아이디어 기록](/ko/guides/capture-an-idea/) 참조. |
  | **Derived (child) idea**(파생된 자식 아이디어) | 자신의 요구사항 구체화, 제안, 작업을 가지고 부모 아이디어에 연결된 완전한 아이디어. [아이디어 기록](/ko/guides/capture-an-idea/) 참조. |

</div>

## 에이전트와 원격 작업

<div class="table-scroll" role="region" aria-label="에이전트와 원격 작업 용어" tabindex="0">

  | 용어 | 정의 |
  | --- | --- |
  | **Session / Conversation**(세션 / 대화) | 에이전트의 한 번의 작업 세션. 데몬의 채팅 화면은 이것들을 대화로, 한 번의 주고받음을 하나의 턴으로 보여 준다. [Chorus 데몬 운영](/ko/guides/daemon-operations/) 참조. |
  | **Daemon**(데몬) | 에이전트를 온라인 상태로 유지해 원격으로 깨워 일을 시킬 수 있게 하는, 상시 실행되는 로컬 프로세스. [Chorus 데몬 운영](/ko/guides/daemon-operations/)과 [원격 에이전트에서 작업 시작](/ko/guides/remote-control/) 참조. |

</div>
