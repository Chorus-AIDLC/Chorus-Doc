코딩 에이전트는 키 하나를 누르는 수준에서는 뛰어나지만 프로젝트 전체에서는 길을 잃습니다. 함수 하나를 작성하라고 하면 빛나지만, 기능 하나를 통째로 맡겨서 요구사항을 확정하고, 계획하고, 작업을 나누고, 만들고, 확인하게 하면 결국 프롬프트를 돌보고 세션마다 맥락을 다시 설명하는 상태로 돌아갑니다. 모델은 점점 똑똑해지는데, 모델을 둘러싼 일은 여전히 수작업입니다.

Chorus는 그 틈을 메우는 계층입니다. Chorus는 **에이전트 하니스**, 즉 모델을 둘러싸는 구조로, 에이전트와 사람으로 이루어진 팀을 거친 아이디어에서 완성된 결과까지 데려갑니다. 모델이 두뇌라면 Chorus는 그 밖의 모든 것입니다. 당신은 에이전트를 키 하나하나로 조종하지 않습니다. 에이전트가 제안하고, 당신이 검증합니다.

## 뒤집힌 대화

대부분의 도구는 한 방향으로 작동합니다. 당신이 프롬프트를 쓰면 AI가 응답하고, 출력이 맞을 때까지 당신이 계속 프롬프트를 씁니다. Chorus는 그 방향을 뒤집습니다.

당신은 거친 아이디어를 던집니다. 예를 들어 *"인증 모듈을 리팩터링해야 해."* 에이전트는 짐작하는 대신 질문을 들고 돌아옵니다. 어떤 제공자인지, OAuth인지 SAML인지. 요구사항이 확정되면 에이전트는 계획을 건넵니다. 짧은 명세와 몇 개의 작업, 그리고 그 사이의 의존 관계까지 정리한 것입니다. 그리고 당신의 승낙을 기다립니다. 그때가 되어서야 코드를 작성하고, 다 끝나면 무턱대고 믿어야 하는 변경 더미가 아니라 테스트가 통과하는 모습을 보여 줍니다.

당신의 역할은 *프롬프트를 쓰는 것*에서 *제안을 검토하는 것*으로 옮겨 갑니다. 변경 비용이 아직 쌀 때 계획을 승인하고, 코드를 작성한 뒤가 아니라 제안 단계에서 잘못된 방향을 잡아냅니다. 이것이 전부입니다. **AI가 제안하고, 사람이 검증한다.**

## 일이 흐르는 방식

모든 아이디어는 같은 경로를 지나며, 명확한 인계 없이는 다음 단계로 넘어가지 않습니다.

**아이디어 → 제안 → 문서 + 작업 → 실행 → 검증 → 완료**

당신이 아이디어를 적습니다. 에이전트가 몇 가지 확인 질문을 던진 뒤, 그 답을 제안으로 바꿉니다. 짧은 명세에, 그것을 만드는 데 필요한 작업과 작업 사이의 의존 관계까지 정리한 것입니다. 당신이 검토하고 승인합니다. 그러면 에이전트가 작업을 가져가 계획이 허락하는 곳에서는 병렬로 진행하고, 진행 상황을 수시로 보고합니다. 무언가가 완료라고 불리기 전에는 반드시 제안이 요구한 내용과 대조해 검증됩니다. 당신은 매 인계마다 자리를 지키면서도 모든 단계를 직접 몰아붙일 필요가 없습니다.

[AI-DLC 워크플로 가이드](/ko/guides/ai-dlc-workflow/)가 이 경로를 처음부터 끝까지 안내합니다.

## 누가 일을 하는가

당신은 검토하는 사람입니다. 실제 작업은 역할과 권한이 서로 다른 여러 에이전트에 나뉘어 있으며, 각 에이전트는 자기 역할이 허용하는 부분만 건드립니다.

- **PM 에이전트**는 아이디어를 제안으로 바꿉니다. 요구사항을 확정하고, 명세를 쓰고, 작업으로 나눕니다.
- **개발 에이전트**는 그 작업을 가져가 코드를 작성하고, 진행 상황을 보고하며, 결과를 검토에 제출합니다. 서로 의존하지 않는 작업이라면 여러 에이전트가 동시에 일할 수 있습니다.
- **관리자 에이전트**는 프로젝트를 관장합니다. 프로젝트를 만들고, 제안을 승인하며, 완료된 일을 검증합니다.

이들은 Claude Code, Codex, OpenClaw, 또는 임의의 MCP 호환 에이전트에서 실행할 수 있습니다. 지원 범위는 [에이전트 플랫폼](/ko/reference/agents/) 참고 문서를 확인하세요.

## 무엇을 얻는가

Chorus는 이 협업이 하나로 이어지게 하는 결합 조직입니다.

- **무슨 일이 일어나는지 볼 수 있습니다.** 어떤 에이전트가, 어떤 하위 에이전트가, 어떤 작업을 하고 있는지 모든 활동이 실시간으로 보입니다.
- **자신의 에이전트를 가져올 수 있습니다.** 특정 공급업체나 모델에 종속되지 않으며, MCP 호환 에이전트라면 무엇이든 참여할 수 있습니다.
- **모든 것이 당신의 것입니다.** Chorus는 AGPL-3.0으로 공개된 오픈 소스이며, 당신 자신의 인프라에서 실행됩니다.
