Chorus 通常运行在[反转对话](/zh/guides/ai-dlc-workflow/)之上：智能体提出提案，你来验证。但每一类实体也都有**手动入口**：你可以亲手编写一个想法、一个任务或一整份提案，也可以编辑、移动、改挂父级或删除已有的实体。本页介绍这些手动操作；至于实体之后经历的生命周期，本页只链接到各阶段指南，不再重复讲解。

## 手动创建想法

想法位于项目**概览**的想法看板中。选择**新建想法**打开对话框，有两种记录方式：

- **填写表单**：给想法填写标题和可选的描述。**设为主题**选项会把它变成用于归拢的主题（通过从它派生的子想法来交付），而不是单一交付物。
- **对智能体描述**：在聊天输入框里把想法讲清楚，让在线智能体和你一起完善它。此模式需要有智能体在线，没有时不可用。你也可以在描述时请智能体把一个大请求拆成若干子想法。

:::note[智能体在做什么]
手动创建的想法进入与其他想法相同的流水线。一旦你把它指派给某个智能体，智能体就会运行需求细化，并起草一份提案供你审核。完整流程见[记录想法](/zh/guides/capture-an-idea/)。
:::

## 编辑、移动或改挂想法

打开一个想法即可看到它的详情面板。在这里你可以**编辑想法**（修改标题和描述）、**删除想法**，或选择**移动到项目...**，将它移到另一个项目；移动对话框会在你确认前预览哪些内容会随想法一起移动。

面板还管理**血缘**，即想法之间的父子关系：

- **挂父** / **更改父级**：把当前想法挂到另一个想法之下，或改挂到别的父想法。
- **派生新想法**：从当前想法派生一个子想法（一个完整的想法，拥有自己的细化、提案和任务）。
- **脱钩（变为顶层）**：解除父级链接，把想法退回顶层。

**设为主题**可在“单一交付物”与“用于归拢的主题”之间切换想法。主题只归拢它的子项，本身不能变成提案，参见[记录想法](/zh/guides/capture-an-idea/#主题想法与派生子想法)中“主题想法与派生子想法”一节。

## 手动创建任务（Quick Task）

大多数任务是在你批准提案时生成的，但当某项工作不需要完整的“想法→提案”流程时，你也可以直接新增一个任务，即快速任务（Quick Task）。在**任务**看板上选择**新任务**，填写标题和描述、**优先级**、工作量预估、**验收标准**（审核者据以验证的清单），以及任何**依赖关系**（用**添加依赖**要求其他任务先完成）。手动创建的任务初始为开放、未指派状态，和从提案生成的任务一样，可以被认领或指派。

:::note[智能体在做什么]
快速任务一经创建就是一个普通任务：把它指派给某个智能体，等它的依赖满足后，智能体会认领、执行，并提交给你验证。认领、指派与状态路径见[执行任务](/zh/guides/run-tasks/)。
:::

## 编辑任务及其依赖

打开一个任务会进入同一个面板，此时标题为**编辑任务**。修改任意字段后选择**保存更改**，或用**删除任务**删除它。该面板还驱动状态路径：**开始工作**、**提交验证**、**标记为已验证**和**分配**。

依赖关系可以从两个方向查看：**依赖于**列出当前任务所等待的上游任务，**被此任务阻塞**列出等待当前任务的下游任务。只有当一个任务所依赖的任务全部完成后，它才能开始。在看板上移动一张仍被阻塞的卡片时会显示警告；如果你确定这样的顺序没有问题，可以选择**强制移动**。

## 手动创建提案

提案通常由 PM 智能体撰写，但你也可以自己写一份。选择**创建提案**，填写标题，并选择这份提案要交付的想法。只有你已认领或被指派的想法可选，列表为空时请先认领一个。创建后会打开提案进行编辑，你在这里组装计划：为每份 PRD、设计或规格用**添加文档**，为每个工作单元用**添加任务**（连同它的验收标准和依赖）。计划完成后，**提交审核**会把它送入与智能体所写提案相同的审批关口。

:::note[智能体在做什么]
无论提案由智能体还是你撰写，批准都是决策关口：审阅并批准其文档和任务草稿后，它们会转为真实的文档和开放状态的任务。批准会创建什么见[审核提案](/zh/guides/review-a-proposal/)。
:::
