当某个智能体运行环境已处于**在线**状态，而你希望 Chorus 在那台机器上开始工作时，可以从 Chorus 远程发起工作。

## 选择运行环境

开始工作前请确认：

- 智能体身份是该项目预期使用的那一个；
- 连接处于**在线**状态；
- 主机是预期的设备；
- 工作目录包含你想修改的项目。

如果项目或任务已固定到某个连接，Chorus 会继续使用该连接的主机和工作目录。该连接离线时，请先恢复它，或者明确选择另一个目标。Chorus 不会悄悄把已固定的工作转移到别处。

:::caution[工作目录决定执行环境]
智能体运行时可以访问所选目录，并使用其后台服务所配置的权限模式。发送指令前请检查目标。
:::

## 开启会话

1. 打开你希望智能体处理的项目条目。
2. 选择开始或继续智能体工作的操作。
3. 选择在线的工作目录。
4. 输入一条具体的指令，写明期望结果和任何约束。
5. 选择**开启会话**。

## 在移动端查看会话

小屏幕上，对话会以接近全屏的面板打开。使用返回按钮回到会话列表，再选择其他对话。
选择一个活跃会话时，即使它不在列表已加载的部分中，也会直接打开。
智能体的会话 ID 可用后，精简的对话记录顶部会提供**复制 session ID**，方便你在终端中继续该会话。

## 观察结果

打开对话，跟进当前轮次和智能体输出。在让会话无人值守之前，请确认它已在所选连接上启动。

如果会话没有启动，先检查目标是否仍然在线。投递失败时请参阅[排查智能体连接故障](/zh/guides/troubleshooting/)；会话已经启动但需要干预时，请参阅[中断与恢复会话](/zh/guides/session-recovery/)。
