Chorus 里的一切都存在于某个**项目**之内：想法、提案、文档和任务都归属于一个项目。本页带你从空白的仪表盘一路走到打开的项目工作区，为记录第一个想法做好准备。这是 [AI-DLC 工作流](/zh/guides/ai-dlc-workflow/)的第一站。

## 打开项目页面

在左侧边栏选择**项目**。页面把你的工作按可折叠的**项目组**卡片组织起来，未分组的内容归在**未分组**一节下。右上角的视图切换按钮可在**列表**和**网格**之间切换。

全新安装时，页面会显示**欢迎使用 Chorus** 引导面板，带你完成与下文相同的两步：先建项目组，再建项目。

## 创建项目组

项目组用来把相关项目放在一起，例如每个产品或团队一个项目组。

1. 在右上角选择**新建项目组**（引导面板中则为**创建项目组**）。
2. 填写**组名称**（例如 `Mobile Apps`）。
3. 选择**可见性**：**公开**（默认值，工作区里的每个人都能找到该项目组）或**私有**（仅限其成员，以及有权访问其中某个项目的人）。参阅[控制谁能看到项目](/zh/guides/project-access/)。
4. 可选填**描述**。
5. 选择**创建分组**。

新项目组会显示为一张卡片，带有**查看仪表盘**链接和它自己的**新建项目**按钮。

## 创建项目

1. 在项目组卡片上选择**新建项目**。对话框会显示**创建到：*项目组名称***，让你清楚项目会创建在哪里。
2. 填写**项目标题**（例如 `Project Alpha`）。
3. 填写**描述**，说明项目的内容。
4. 选择**可见性**：**公开**或**私有**。新项目默认采用所在项目组的可见性；在私有项目组内，项目必须为私有，并继承该项目组的角色。你会成为自己所创建项目的管理员。
5. 可以现在就在 **Agent 工作目录**一节设置工作目录（见下文），也可以留待以后再设。
6. 选择**创建项目**。

Chorus 会创建项目并把它加入该项目组。请求进行期间再次选择**创建项目**或按下 Enter，不会创建第二个项目。

:::caution[如果结果未能确认]
如果 Chorus 无法确认结果，例如请求耗时超过 20 秒或连接中断，对话框会给出提示并保留你的草稿。此时项目仍可能已经创建成功。请先关闭对话框，检查或刷新项目列表，再重新尝试：再次创建需要选择**我已检查列表，仍要再次创建**，因为这可能产生重复项目。如果你关闭对话框后那次请求其实已成功，下次打开对话框时它会告诉你，此时创建另一个项目需要选择**我仍要创建另一个项目**。
:::

## 固定工作目录

工作目录是主机上的一个文件夹，已连接的智能体在处理本项目时会读写这个文件夹。它是**按智能体分别设置的**，而不是整个项目共用一个路径。

在项目的 **Agent 工作目录**设置中，你可以为每个智能体：

- **配置工作目录**：选择一台主机和一个目录。
- **替换工作目录**：把智能体指向另一个目录。
- **清除固定工作目录**：移除已固定的路径。

目录固定之后，项目**概览**页头会为该智能体显示一个带路径的锁形标记。只有目录所在的主机在线时，该目录才可选；这些主机和目录是在你连接智能体运行环境时注册的。

### 固定目录会带来什么

固定目录会把项目**绑定**到某一个在线智能体和某一个工作目录，并在三个方面改变 Chorus 的行为：

- **不再弹出目录选择。** 项目固定目录后，你之后从该项目发起的智能体工作（以对话方式创建想法、运行需求细化、派发任务）都会直接交给那个智能体和目录。Chorus 不再每次都让你选择目录，而是自动使用已固定的选择。
- **该选择成为一个持久目标。** 你固定的路径会被记录为具体的智能体、主机和目录的组合，而不只是一条文件夹路径。这正是[在线智能体总览](/zh/guides/online-agents-overview/)中所说的那类目标，会话也绑定在这个目标上。
- **进行中的工作受到保护。** 如果你之后**替换**或**清除**固定目录，只有*今后*的工作才会采用新设置。此前已绑定到旧目录的想法或会话会继续在那里运行，更改项目偏好绝不会把进行中的工作移到另一个目录。

因此，固定目录既是默认（新工作无需询问即落到那里），也是保证（已经开始的工作留在它开始的地方）。

## 打开工作区

选择项目卡片，即可在**概览**打开它的工作区。此时侧边栏会显示该项目的导航：

<div class="table-scroll" role="region" aria-label="项目工作区导航" tabindex="0">

  | 区域 | 承载的内容 |
  | --- | --- |
  | 概览 | 想法看板（你在这里记录并跟进想法）以及项目的工作目录标记和设置。 |
  | 文档 | 已批准的文档和完成报告。 |
  | 提案 | 等待你审核的提案，以及已批准的提案。 |
  | 任务 | 项目任务的看板与依赖图。 |
  | 图谱 | 项目中想法、提案、任务和文档的思维导图。 |
  | 动态 | 项目中所有操作的动态流。 |

</div>
