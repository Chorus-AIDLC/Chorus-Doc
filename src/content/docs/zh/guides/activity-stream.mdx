当智能体和人在一个项目上并行工作时，你需要一个地方来回答“刚刚发生了什么”。**动态**视图就是这个地方：它实时记录项目上的重要
操作，最新的排在最前，让你一眼就能跟上进度，而不必逐个打开实体去查看。

## 打开动态记录

每个项目的导航里都有一个**动态**入口。打开它就能看到该项目的完整记录；条目按天分组（今天、昨天，再往前按日期），
每条都标有相对时间，近期事件一目了然。项目仪表盘上也有指向最近动态的链接，不离开概览就能快速浏览。

每条记录描述的是“谁”对“哪个”实体做了“什么”，例如某个智能体认领了一个任务、某人批准了一份提案，或者一个想法
进入了需求细化。记录的操作覆盖整个生命周期：

- **任务**：创建、指派、认领、开始、提交审核、完成、释放，以及状态变更。
- **想法**：创建、指派、认领、释放、编辑、变更父级，以及状态变更。
- **需求细化**：开始、作答、跳过、完成，以及请求追加细化。
- **提案与文档**：创建、批准、拒绝，以及撤回。

## 谁做了什么

操作者是执行该操作的已认证用户或智能体，不会自动变成任务负责人或智能体的人类所有者。通过界面/API 编辑任务、通过 MCP 提交验证，以及通过工作报告改变状态时，执行历史会保留实际调用者，而不是标成 System。姓名和头像帮助区分人和智能体。

工作者在 `chorus_update_task`、`chorus_report_work` 等支持的调用中传入有效 `sessionUuid` 时，会话归属会补充上下文，但不会替代已认证操作者。并非每条事件都带子智能体会话。会话追踪参阅[管理智能体与 API 密钥](/zh/guides/manage-agents/)。

如果项目刚创建或近期没有操作，视图会直接提示暂无动态；随着你和智能体开展工作，记录会逐步增加。若你想查看与**你自己**
相关的通知，而不是整个项目的记录，请参阅[通知](/zh/guides/notifications/)。
