本页介绍与账号相关的各项操作：登录、在多个工作区之间选择、首次上手向导、语言与主题设置，以及退出登录。如果你是第一次在自己的电脑上安装
Chorus，请先看[快速开始](/zh/guides/getting-started/)，那里介绍了基于邮箱/密码的本地安装，本页不再重复。

## 登录

输入邮箱或本地用户名并选择**继续**。Chorus 会先识别可用的登录方式，再要求输入密码：

- **本地工作区账号**：使用邀请中的用户名或邮箱，按提示选择工作区，再输入密码。用户名和邮箱不区分大小写。
- **单点登录（SSO）**：输入邮箱，在工作区的身份提供方完成认证。
- **Default Auth**：通过 `DEFAULT_USER` 和 `DEFAULT_PASSWORD` 配置的单个账号使用邮箱及部署密码，与受管理的本地工作区账号不同。
- **多个身份**：选择目标本地工作区、SSO 工作区、默认账号或超级管理员身份。配置默认账号不会跳过身份选择。

本地工作区使用本地账号，不在同一工作区同时启用 OIDC。同一邮箱仍可在其他工作区拥有独立身份。部署配置见[超级管理员与认证配置](/zh/guides/authentication-setup/)。

### 接受邀请或重置密码

打开管理员私下分享的链接，设置至少 8 个字符、最多 72 个 UTF-8 字节的密码。链接 24 小时后过期，只能使用一次；重新签发会替换旧链接。Chorus 不会自动发送邮件。完成设置不会自动登录：请返回登录页，使用用户名或邮箱及新密码登录。需要新邀请或重置链接时，请联系工作区管理员；不提供公开注册或自助密码重置。

## 选择工作区

仅匹配多个 SSO 工作区时，选择页显示工作区名称和身份提供方。如果还匹配本地账号或其他登录方式，则使用身份选择界面。输入密码前先确认工作区；不同工作区中相同的用户名或邮箱并不代表共享账号。你可以返回并修改登录标识。

## 首次上手

第一次进入一个全新的工作区时，Chorus 会打开一个六步的上手向导。你可以先跳过，以后再完成。向导包含以下步骤：

1. **欢迎**：概览你的工作将依次经过的流水线：**想法 → 提案 → 任务 → 执行 → 验证 →
   完成**。
2. **创建智能体**：为一个 AI 智能体命名并选择它的权限；Chorus 会为它生成一个 API
   密钥。（完整的智能体设置见[为智能体创建访问权限](/zh/guides/administrator-setup/)，这里只是内嵌的快速版本。）
3. **复制密钥**：把它妥善保存，它只显示这一次。
4. **安装**：选择你的智能体客户端（Claude Code、Codex、Kiro、OpenCode、OpenClaw
   或其他），并按它展示的步骤完成安装。
5. **测试**：Chorus 会等待你的智能体连接，然后确认。
6. **完成**：一张设置摘要，并提供前往项目和设置的快捷入口。

你随时可以从**设置**重新打开向导。

:::note[智能体在做什么]
**创建智能体**和**测试**两步分别用来设置和验证一个 AI 智能体身份。你创建智能体并安装好它的客户端后，智能体会自己连接到
Chorus；**测试**步骤只是等待这次连接。
:::

各客户端平台如何连接、如何运行，请参阅[智能体平台](/zh/reference/agents/)参考页。

## 显示名称与头像

打开**设置**编辑自己的个人资料。这些功能适用于已登录的本地、OIDC 和 Default Auth 用户，不适用于智能体 API 密钥或超级管理员面板。

- **显示名称**：去除首尾空白后须为 1–32 个 Unicode 码点。支持表情符号，组合表情可能按多个码点计数。选择**保存**，或在输入法组合输入结束后按 Enter 保存；**取消**会丢弃草稿。修改的是显示名称，不是登录用户名或邮箱；自定义名称不会被后续 OIDC 登录覆盖。
- **头像**：选择**随机生成**预览生成式头像，可反复尝试，满意后选择**保存**。选择**取消**或离开页面会丢弃未保存的预览。这不是图片上传入口。

输入或随机生成本身不会保存。请等待保存成功提示；保存失败时，原来的资料保持不变，你可以重试。名称与头像分别保存。保存后会更新当前账号的显示，重新加载后仍然有效，不会修改其他工作区的身份。

## 语言与主题

你的显示偏好位于侧边栏底部。

- **主题**：选择**浅色**、**深色**或**跟随系统**（与操作系统的设置保持一致）。
- **语言**：选择 **English**、**中文**、**한국어** 或 **日本語**，界面会立即切换。你也可以在
  **设置**页面切换语言。

## 退出登录

侧边栏底部有一个**退出登录**按钮。选择它会结束当前会话并回到登录界面，你可以在那里用同一个或其他邮箱重新登录。
