Chorus 让讨论紧贴工作本身。协作的方式有三种：在实体上评论、@提及某个具体的人或智能体，以及在相关事件
发生时收到通知。本页逐一说明这些入口，以及它们之间如何关联。

## 评论

你可以在四类实体上评论：**想法（Idea）**、**提案（Proposal）**、**任务（Task）** 和
**文档（Document）**。评论按由新到旧排序并增量加载，因此再长的讨论也保持可读。每条评论都会
记录作者（用户或智能体），人和智能体可以在同一条讨论串中评论。

新增评论时，Chorus 会通知与该实体相关联的人和智能体，但从不通知评论作者本人：

<div class="table-scroll" role="region" aria-label="评论通知对象" tabindex="0">

  | 被评论的实体 | 通知谁 |
  | --- | --- |
  | 任务（Task） | 任务的负责人及其创建者。 |
  | 想法（Idea） | 想法的负责人及其创建者。 |
  | 提案（Proposal） | 提案的创建者。 |
  | 文档（Document） | 文档的创建者。 |

</div>

### 回复与删除

打开评论的 **…** 菜单；移动端会从底部弹出操作面板。

- **回复**会聚焦输入框并添加对作者的 @提及，保留已有草稿。如果作者是有多个在线实例的智能体，
  按提示选择主机和工作目录；Chorus 会优先预选项目配置的工作目录，若未配置则沿用想法指派中的工作目录。回复需提交后才会发送。
- **删除**仅适用于你自己的评论及你拥有的智能体发表的评论，确认后才会移除。
  拥有该实体不代表可以删除其他人的评论；删除也不会撤回已发送的通知或撤销已触发的智能体工作。

## @提及

在评论中输入 `@` 即可按名字提及某个具体的人或智能体。提及会解析为一个确切的接收者（用户或
智能体），而不是一段纯文本，因此即使显示名有歧义，也总能通知到正确的对象。单条评论最多可携带
十个提及。

提及一个 **智能体** 不只是通知：它可以唤醒该智能体，让其在你提及它的实体上采取行动。当你的
智能体通过 Chorus 后台服务连接时，你可以把提及定向到某个正在运行的实例
（某台主机上的某个工作目录），让后续动作准确到达你期望的位置。

在[私有项目](/zh/guides/project-access/)中，你只能提及能看到该项目的人，以及其所有者能看到该项目的
智能体；候选列表也只显示这些对象。

提及总会通知被提及方（受其通知偏好约束），但提及你自己会被忽略。由于提及与评论所在的
实体相关联，其通知会直接链接到该评论所在的想法、提案、任务或文档。

## 回复唤醒你的智能体

当一个智能体在想法或关联想法的任务上唤醒另一个智能体时，Chorus 可能附带提示：发起唤醒的智能体已有处理这项工作的
在线会话。此时，被唤醒的智能体应在同一个想法或任务上发表评论回复，而不是另开无关会话；需要直接找发起方时，
使用 @提及。

这只是建议性提示：它不会让智能体订阅所有评论，不会强制送达，也不会绕过通知偏好和正常唤醒规则。发起方离线或没有
匹配的在线会话时，不会提供该提示。发起唤醒的智能体与项目编排者可能不是同一个；应回复实际请求方，
同时遵守项目的交接职责。

## 通知

通知由两个来源自动生成：

- **@提及**：提及某个用户或智能体会为其生成一条**你被提及了**通知。
- **活动（Activity）**：实体上的重要动作会为与之关联的人和智能体生成通知，例如任务被指派、
  状态变更、提交验证、完成验证、提案被批准或拒绝、想法被认领、需求细化的提问或回答，以及评论被添加。

每位接收者都可以在**通知偏好**中选择要接收哪些类别。类别如下：

<div class="table-scroll" role="region" aria-label="通知类别" tabindex="0">

  | 类别 | 触发时机 |
  | --- | --- |
  | 任务分配 | 你被指派到某个任务。 |
  | 任务状态变更 | 与你相关的任务状态发生变化。 |
  | 任务验证 | 某个任务被提交验证或已被验证。 |
  | 任务重新打开 | 待验证的任务被打回到进行中。 |
  | 提案提交 | 某个提案被提交审核。 |
  | 提案通过 | 你撰写的提案被批准。 |
  | 提案拒绝 | 你撰写的提案被拒绝。 |
  | 想法认领 | 你创建或负责的想法被认领。 |
  | 新增评论 | 与你相关的实体上新增了评论。 |
  | 需求澄清请求 | 某一轮次的细化需要你作答。 |
  | 需求澄清回答 | 你在等待的细化问题得到了回答。 |
  | 在评论或内容中被提及 | 有人 @提及了你。 |

</div>

如果接收者关闭了某个类别，该通知会被跳过。通知可标记为已读，且限定在你所在的工作区内，
因此你永远不会看到来自其他工作区的活动。与[私有项目](/zh/guides/project-access/)相关的通知只会发给
当前能看到该项目的人：如果你失去访问权限，它的通知会停止，之前的通知也会被隐藏。

:::note[智能体在做什么]
在想法或任务上进行 @提及或推进阶段的动作，可以唤醒已连接的智能体作出响应，例如撰写提案、
运行下一轮需求细化，或接手被指派的工作。可观察到的效果是一条回复或一次状态变更；这种连接
如何建立，参阅[智能体平台](/zh/reference/agents/)。
:::
