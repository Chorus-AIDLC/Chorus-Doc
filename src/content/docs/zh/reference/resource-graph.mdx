每个项目都有一张**资源图（resource graph）**：从项目侧边栏的**图谱**打开的思维导图视图，
把整个项目铺陈为相互连接的节点。它用一张图展示每个实体及它们之间的连线，从而回答"这个项目的
工作是如何组合在一起的？"。资源图限定在单个项目内，绝不会混入其他项目或公司的工作。

## 资源图展示什么

资源图绘制四类节点，每类都有自己的颜色和图标：

<div class="table-scroll" role="region" aria-label="资源图节点" tabindex="0">

  | 节点 | 代表 | 节点上显示的状态 |
  | --- | --- | --- |
  | 想法（Idea） | 项目中的一个想法。 | 其派生的看板状态（例如规划中、开发中、验收成果、已完成）。 |
  | 提案（Proposal） | 一个提案。 | 其原始状态（draft、pending、approved、closed）。 |
  | 任务（Task） | 一个任务。 | 其原始状态（open、assigned、in_progress、to_verify、done、closed）。 |
  | 文档（Document） | 一个已物化的文档。 | 其文档类型（例如 PRD、技术设计、规格说明、总结报告）。 |

</div>

当某个智能体正在查看或编辑某个实体时，对应节点还会显示一个实时在场（presence）光环，
让你能实时看到活动。

## 实体如何连接

节点之间的连线展示一个实体如何催生另一个实体。共有三类连线：

<div class="table-scroll" role="region" aria-label="资源图连线" tabindex="0">

  | 连线 | 方向 | 含义 |
  | --- | --- | --- |
  | 脉络（Lineage） | 父想法 → 子想法 | 一个派生的子想法从父（主题）想法中拆分出来。 |
  | 派生（Derivation） | 想法 → 提案、提案 → 任务、提案 → 文档 | 从某个想法提出了提案，批准该提案后物化出其任务与文档。 |
  | 依赖（Dependency） | 前置任务 → 下游任务 | 下游任务在上游完成之前处于阻塞状态。 |

</div>

把这些连线合在一起看，就能追溯一项工作走过的完整路径：从一个父想法，向下经过它的子想法及其
提案，再延伸到某个提案产出的文档，以及任务之间的依赖图。这与[实体生命周期参考](/zh/reference/lifecycle/)
中描述的依赖关系相同，只是以可视化方式呈现。

## 使用资源图

资源图按派生深度从左到右布局，并随工作变化实时更新。你可以：

- **平移与缩放**：拖拽、滚动、双指捏合，或使用屏幕上的控件，并可将整张图重新适配到视野内。
- **展开或折叠**某个枢纽：想法可展开为其提案，提案可展开为其任务与文档，让你从全局入手、逐层深入。
- 用类型图例**筛选**要显示的节点类型。
- 按标题**搜索**节点；匹配项会被高亮，其父枢纽会自动展开。
- 点击节点**打开**对应实体，在侧边面板中展示该想法、提案、任务或文档，而无需离开资源图。

:::note[智能体在做什么]
资源图会反映智能体所做的工作，它们撰写的提案、它们物化并完成的任务，因此它们的进展会在
这里实时显现。关于智能体如何连接，参阅[智能体平台参考](/zh/reference/agents/)。
:::
