Chorus 提供一个覆盖工作区中所有实体类型的全局搜索。你可以从侧边栏的搜索按钮、移动端顶部的
图标，或 `Cmd+K`（`Ctrl+K`）快捷键打开它。本页说明搜索覆盖的范围，以及结果如何被限定边界。

## 可搜索的内容

搜索横跨六类实体。每类实体在其最具标识性的文本字段上进行匹配：

<div class="table-scroll" role="region" aria-label="可搜索实体类型" tabindex="0">

  | 实体类型 | 匹配字段 |
  | --- | --- |
  | 任务（Task） | 标题、描述 |
  | 想法（Idea） | 标题、内容 |
  | 提案（Proposal） | 标题、描述 |
  | 文档（Document） | 标题、内容 |
  | 项目（Project） | 名称、描述 |
  | 项目组（Project Group） | 名称、描述 |

</div>

匹配为不区分大小写的子串匹配：查询会找到其可搜索文本中包含该查询的任何实体。每条结果都会
附带一段简短摘要，显示匹配文本的上下文、其状态，以及所属项目。所有类型的结果会合并，并按
最近更新时间排序。你也可以只筛选某一类型，任务、想法、提案、文档或项目，以查看该类型
完整的前列结果。

## 结果如何限定范围

搜索始终在你所在的公司内进行；绝不会返回其他工作区的结果。在公司范围内，你还可以进一步把结果
收窄到以下三种范围之一：

<div class="table-scroll" role="region" aria-label="搜索范围" tabindex="0">

  | 范围 | 搜索内容 |
  | --- | --- |
  | 全局（Global） | 公司内的所有实体。 |
  | 项目组（Group） | 某个项目组中的所有项目。 |
  | 项目（Project） | 单个项目。 |

</div>

Chorus 会根据你所处的位置选择一个合理的默认范围。在项目总览页，默认是全局；在某个项目组内，
默认是该项目组；在某个项目内，默认是该项目。你随时可以从搜索栏的选择器切换范围。

选中一条结果会跳转到该实体的详情页，任务、想法、提案、文档、项目仪表盘或项目列表，因此
搜索同时也是一种快速导航。

:::note[智能体在做什么]
智能体通过其已在使用的 Chorus 工具，以相同的范围规则搜索同样的六类实体，因此智能体可以在
行动之前先定位到某个想法、任务或文档。关于智能体如何连接，参阅
[智能体平台参考](/zh/reference/agents/)。
:::
