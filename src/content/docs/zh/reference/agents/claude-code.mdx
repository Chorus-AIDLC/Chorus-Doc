# Claude Code

Claude Code 是 Chorus 第一方支持的运行后端。安装插件后，你可以在 Claude Code 中使用 Chorus 工具和技能；安装 Chorus 后台服务后，还可以从 Chorus 远程启动、查看、中断和恢复会话。

## 安装插件

最快的方式是使用 `chorus` 命令行工具，它会为你安装插件并保存凭据：

```bash
npm install --global @chorus-aidlc/chorus
chorus agents add --agents claude
```

在提示时输入 Chorus 地址和智能体密钥。`chorus agents add` 会替你运行
`claude plugin marketplace add` / `claude plugin install`，并把 `CHORUS_URL`、
`CHORUS_API_KEY` 和 `CHORUS_AGENT_PROFILE` 写入用户全局 `~/.claude/settings.json` 的 `env` 块，
因此交互式 Claude Code 会话无需手动设置环境变量即可完成认证。完成后重新启动 Claude Code。

若要改为手动安装，请在启动 Claude Code 的终端中设置凭据：

```bash
export CHORUS_URL="https://chorus.example.com"
export CHORUS_API_KEY="cho_REDACTED"
```

然后在 Claude Code 中添加插件：

```text
/plugin marketplace add Chorus-AIDLC/chorus
/plugin install chorus@chorus-plugins
```

重新启动 Claude Code，使插件和技能生效。

## 启用远程启动

如果只在 Claude Code 终端中使用 Chorus，可以跳过这一步。需要从 Chorus
远程发起工作时，请按照[连接智能体运行环境](/zh/guides/operator-onboarding/)
选择 `claude-code` 运行后端。先在前台确认连接无误，再按照
[管理后台服务](/zh/guides/daemon-operations/)让它保持在线。

## 验证连接

1. 在 Claude Code 中运行 `/plugin list`，确认 `chorus@chorus-plugins` 已启用。
2. 输入 `check in to chorus`，确认 `chorus_checkin` 返回正确的智能体身份和权限。
3. 如果启用了远程启动，在 Chorus 的在线智能体列表中确认运行后端和工作目录均已显示。

## 能力与限制

- Chorus 官方维护插件、MCP 工具、工作流技能和生命周期钩子。
- 后台服务支持远程启动会话、追加指令、中断和恢复。
- 远程任务继承运行后台服务的本地用户权限，因此只注册必要的工作目录。
- 管理员预设适合需要审批方案或验证任务的智能体；普通开发工作优先使用开发者预设。

## 从终端恢复会话

要在自己的终端里接管正在进行的会话，先在对话界面复制它的 session id（对话记录顶部的复制 session ID），然后在该会话原本的工作目录下运行：

```bash
claude --resume <sessionId>
```

复制到的 id 与 Chorus 恢复会话时传给 Claude Code 的 id 一致；对于 Claude Code 运行后端，它就是对应直接想法的 UUID。完整流程见[中断与恢复会话](/zh/guides/session-recovery/#从终端接管会话)。

## 常见问题

- **插件命令不存在**：重新启动 Claude Code，并用 `/plugin list` 检查插件是否启用。
- **`chorus_checkin` 返回 `401`**：创建或轮换智能体密钥，然后重新运行 `chorus agents add`（或更新 `~/.claude/settings.json` 中的 `env` 块），再重新启动 Claude Code。
- **在线智能体列表中没有 Claude Code**：运行 `chorus daemon status`；需要进一步排查时运行 `chorus daemon logs`。
- **工作目录错误**：使用正确的绝对路径重新执行 `chorus daemon install --agent claude-code --cwd ...`。
